# 2. GitHub: push и pull

Коммиты из части 1 лежат только в Codespace. Преподаватель их не видит, а если
Codespace удалить или не открывать 30 дней, история пропадёт. Поэтому их отправляют
в **удалённый репозиторий** (remote repository) — `pond` на github.com. Его имя
в командах — `origin`. Связь Codespace с ним уже настроена.

## `git push` — отправить коммиты в GitHub

```
$ git push
Enumerating objects: 8, done.
Counting objects: 100% (8/8), done.
Delta compression using up to 2 threads
Compressing objects: 100% (4/4), done.
Writing objects: 100% (6/6), 580 bytes | 580.00 KiB/s, done.
Total 6 (delta 0), reused 0 (delta 0), pack-reused 0 (from 0)
To https://github.com/ЛОГИН/pond
   384560f..127484c  main -> main
```

Числа у тебя другие. Строки до `To` пропусти. `384560f..127484c` — последний коммит
на GitHub был и стал; `main -> main` — твоя ветка `main` отправлена в `main` на GitHub.
Проверить: на странице `pond` над списком файлов — сообщение последнего коммита.

Порядок после каждой задачи, в корне `pond`:

```sh
git status
git add .
git commit -m "Жабка представляется по имени"
git push
```

`git pull` — обратное: забрать из GitHub коммиты, которых нет в Codespace. Понадобится
позже.

## Комментарии к коммиту

Разбор задачи пока идёт в комментариях к коммиту на GitHub. Открой `pond` и нажми
справа над списком файлов **N Commits** (на узком экране — иконка часов).

![Ссылка на историю коммитов](images/01-commits-link.png)

*1 — иконка истории коммитов.*

В списке нажми на сообщение коммита — откроется его страница с изменениями. Внизу —
поле **Comment**: ответ на «Вопрос к разбору» пиши туда и нажимай зелёную кнопку
**Comment**. Синяя **+** у строки (появляется при наведении или нажатии на строку) —
комментарий к одной строке, для ответа не нужен.

![Страница коммита](images/02-commit-comment.png)

*1 — кнопка **+** у строки, 2 — поле общего комментария. Subscribe и остальное
не трогай.*

О комментариях преподавателя GitHub пришлёт уведомление на почту и в колокольчик
справа вверху. Отвечать — полем под его комментарием.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `! [rejected] ... (fetch first)` | В GitHub есть коммиты, которых нет у тебя: `git pull`, затем `git push` |
| `Everything up-to-date` | Отправлять нечего, это не ошибка |
