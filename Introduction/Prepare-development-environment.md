# Подготовка среды разработки: GitHub Codespaces

На iPad нельзя установить Go напрямую: iPadOS не позволяет запускать компиляторы.
Поэтому мы будем писать код в **GitHub Codespaces** — это настоящий Linux-компьютер
в облаке с редактором VS Code, который открывается прямо в Safari. Для учёбы он
бесплатен: 60 часов в месяц.

Весь курс ты будешь делать одну программу — «Пруд». Она живёт в твоём собственном
репозитории `pond`, а этот репозиторий, GO-Educate, — учебник: уроки и тексты задач
читаются прямо на github.com. Codespace создаётся для `pond`.

Раз ты читаешь этот текст, аккаунт GitHub у тебя уже есть. Остаётся создать репозиторий,
описать в нём среду, создать Codespace и проверить, что всё работает — это 20–30 минут.

---

## Что понадобится

- iPad с клавиатурой. Трекпад или мышь очень желательны.
- Safari (другие браузеры тоже подойдут, но инструкция написана под Safari).

---

## Шаг 1. Свой репозиторий `pond`

1. Открой [github.com/new](https://github.com/new).
2. **Repository name** — `pond`.
3. Выбери **Private**.
4. Отметь **Add a README file**: Codespace нельзя создать для совсем пустого
   репозитория. Текст README ты перепишешь в первой задаче.
5. Нажми **Create repository**.
6. Добавь преподавателя, чтобы он мог читать твой код: **Settings → Collaborators →
   Add people**, логин `d-listopad`.

---

## Шаг 2. Описание среды

Codespace собирается по файлу `.devcontainer/devcontainer.json`: в нём сказано,
какую версию Go поставить и какие расширения редактора включить. Образец лежит
в GO-Educate, его нужно скопировать в `pond`.

1. На странице `pond` нажми **Add file → Create new file**.
2. В поле имени набери `.devcontainer/devcontainer.json`. После косой черты GitHub
   сам превратит `.devcontainer` в папку.
3. Вставь содержимое файла
   [`.devcontainer/devcontainer.json`](../.devcontainer/devcontainer.json)
   из GO-Educate: открой его, нажми **Copy raw file** (иконка с двумя листами) и вставь.
4. Нажми **Commit changes…**, затем ещё раз **Commit changes**.

---

## Шаг 3. Создание Codespace

1. На странице репозитория `pond` нажми зелёную кнопку **`<> Code`**.
2. Перейди на вкладку **Codespaces**.
3. Нажми **Create codespace on main**.
4. Подожди. В первый раз сборка занимает 2–4 минуты: GitHub скачивает образ с Go
   и ставит расширения. Экран «Setting up your codespace» — это нормально.
5. Когда всё готово, откроется VS Code: слева дерево файлов (Explorer), в центре редактор,
   снизу терминал.

> Если iPad в портретной ориентации, поверни его горизонтально: часть элементов GitHub
> прячется на узком экране.

---

## Шаг 4. Проверка, что Go работает

1. Открой терминал: меню **☰ → Terminal → New Terminal** или сочетание **Ctrl + `**
   (клавиша слева от «1»).
2. Введи команду и нажми Enter:

   ```sh
   go version
   ```

   Ответ должен быть вида `go version go1.26.x linux/amd64`.

3. Создай файл для проверки: в Explorer нажми на иконку **New File** (лист с плюсом),
   назови файл `hello.go` и вставь в него:

   ```go
   package main

   import "fmt"

   func main() {
       fmt.Println("Привет, Go!")
   }
   ```

4. В терминале запусти:

   ```sh
   go run hello.go
   ```

   Если видишь `Привет, Go!` — среда готова.

5. Удали `hello.go`: правый клик на файле в Explorer → **Delete**. Этот файл не нужно
   сохранять в репозиторий.

> Если терминал пишет `go: command not found`, контейнер собрался неправильно.
> Нажми **Cmd + Shift + P**, набери `Rebuild Container` и выбери
> **Codespaces: Rebuild Container**.

## Шаг 5. Настройка Safari и клавиатуры на iPad

**Полный экран.** Разверни Safari на весь экран и работай в горизонтальной ориентации.

**Отдельное окно без вкладок.** Когда Codespace открыт, нажми кнопку **Поделиться →
На экран «Домой»**. Codespace появится как отдельное приложение: без адресной строки
и вкладок Safari, а сочетания клавиш не будут перехватываться браузером.

**Осторожно с Cmd + W.** В обычном Safari это закрывает вкладку целиком, а не файл
в редакторе. Чтобы закрыть файл, используй **Cmd + Shift + P → Close Editor** или крестик
на вкладке файла.

**Полезные сочетания VS Code:**

| Сочетание | Действие |
|---|---|
| Cmd + Shift + P | Палитра команд — через неё доступно всё |
| Cmd + P | Быстрый переход к файлу по имени |
| Ctrl + ` | Показать / скрыть терминал |
| Cmd + B | Показать / скрыть панель файлов |
| Shift + Alt + F | Отформатировать файл |

**Раскладка.** Код пишется в английской раскладке. Переключение — клавиша с глобусом
или Ctrl + Пробел, в зависимости от клавиатуры.

**Автосохранение** уже включено: файлы сохраняются сами через секунду после правки.

## Шаг 6. Как сохранять работу

Codespace — временная машина. Если не заходить в него 30 дней, GitHub удалит его вместе
со всеми файлами, которые не были отправлены в репозиторий. Поэтому работу нужно
отправлять в GitHub. Это делается двумя командами git: **commit** (зафиксировать
изменения) и **push** (отправить на сервер).

Каждая задача курса — отдельный коммит. Сообщение коммита говорит, что теперь умеет
программа: «Жабка представляется по имени», а не «задание 1».

Через интерфейс: иконка **Source Control** слева (три кружка с линиями) → в поле
**Message** напиши, что сделала → **Commit** → **Sync Changes**.

Или в терминале:

```sh
git add .
git commit -m "Жабка представляется по имени"
git push
```

Имя и почта для коммитов в Codespaces настраиваются автоматически из твоего аккаунта
GitHub, ничего вводить не нужно.

## Шаг 7. Остановка, повторный запуск и лимиты

**Остановка.** Codespace сам останавливается через 30 минут бездействия. Вручную:
**Cmd + Shift + P → Codespaces: Stop Current Codespace**. Остановленный Codespace
не расходует часы.

**Повторный запуск.** Открой [github.com/codespaces](https://github.com/codespaces),
найди свой Codespace в списке и нажми на его имя. Или снова через репозиторий `pond`:
**Code → Codespaces** — там будет уже созданный Codespace, его нужно открыть,
а не создавать новый.

**Лимиты бесплатного тарифа:**

| Ресурс | Лимит |
|---|---|
| Время работы | 60 часов в месяц на 2-ядерной машине |
| Хранилище | 15 ГБ |
| Хранение остановленного Codespace | 30 дней без активности, потом удаление |

Часы списываются с **твоего** аккаунта.
Посмотреть остаток: **Settings → Billing and plans → Plans and usage → Codespaces**.

**Чтобы часы не утекали:**

- Не создавай несколько Codespace для одного репозитория. Нужен ровно один.
- Уменьши время до автоостановки: **Settings → Codespaces → Default idle timeout**,
  например 15 минут.
- Закончила заниматься — останови Codespace вручную.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Нет вкладки Codespaces на странице репозитория | Проверь, что ты вошла в свой аккаунт GitHub |
| Codespace собрался, но `go` не найден | Проверь, что `devcontainer.json` лежит именно в папке `.devcontainer` в корне `pond`, затем **Rebuild Container** |
| Экран «Setting up your codespace» висит больше 5 минут | Обнови страницу |
| `go: command not found` | Cmd + Shift + P → **Codespaces: Rebuild Container** |
| Расширение Go предлагает установить инструменты (gopls и другие) | Нажми **Install All** и подожди |
| Пропали несохранённые файлы | Codespace был удалён. Пересоздай его и в следующий раз делай push |
| Закончились 60 часов | Ждать начала следующего месяца или спросить у преподавателя про запасной вариант |
