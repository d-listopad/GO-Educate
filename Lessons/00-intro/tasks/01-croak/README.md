# Задание 1. Жабка квакает

## Контекст

Весь курс мы будем писать программу о жабках. Пока жабка умеет ровно одно: квакать.
Первое «Ква!» на экране — это и есть начало программы.

## Что сделать

В файле `main.go` напиши программу, которая печатает одну строку:

```
Ква!
```

Используй `fmt.Println`, как в разборе файла из урока.

## Пример

```
$ go run .
Ква!
```

## Как проверить

В папке задания выполни:

```sh
go test
```

Готово, когда все тесты зелёные.

<details>
<summary>Подсказка</summary>

Файл состоит из трёх частей: `package main`, `import "fmt"`, `func main()`.
Внутри `main` — один вызов `fmt.Println`. Если забыть `import`, редактор добавит его
сам при сохранении файла.

</details>
