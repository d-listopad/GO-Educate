# Задание 2. Жабка квакает громко

## Контекст

Жабка квакает, но с другого берега пруда её не слышно. Нужно квакнуть ещё раз,
громко — заглавными буквами.

## Что сделать

Напиши программу, которая печатает две строки:

```
Ква!
КВА!
```

Вторую строку получи не вручную, а функцией `ToUpper` из пакета `strings`:
она возвращает копию строки, где все буквы заглавные. Для этого понадобятся два пакета,
`fmt` и `strings`.

## Пример

```
$ go run .
Ква!
КВА!
```

## Как проверить

В папке задания выполни:

```sh
go test
```

Готово, когда все тесты зелёные.

<details>
<summary>Подсказка</summary>

Два импорта записываются группой в скобках, по одному в строке. Результат
`strings.ToUpper("Ква!")` можно передать прямо в `fmt.Println(...)`, без промежуточных
шагов.

</details>
