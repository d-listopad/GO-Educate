# Задание 3. Почини программу

## Контекст

Это задание не про жабок. Оно про чтение сообщений компилятора — навык, который
понадобится в каждом следующем задании курса.

## Что сделать

Ниже программа с тремя ошибками. Перенеси её в `main.go` целиком, вместо заготовки,
затем выполни `go run .`, прочитай сообщение компилятора, исправь одну ошибку и запусти
снова. Повторяй, пока программа не напечатает:

```
Все ошибки исправлены.
```

Программа с ошибками:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	fmt.println("Все ошибки исправлены.")
```

## Пример

Первый запуск покажет одну ошибку, например:

```
$ go run .
# go-educate/Lessons/00-intro/tasks/03-fix-errors
./main.go:10:1: syntax error: unexpected EOF, expected }
```

Читается так: файл `main.go`, строка 10, столбец 1, описание ошибки. Таблица типичных
ошибок есть в конце урока.

## Как проверить

В папке задания выполни:

```sh
go test
```

Готово, когда все тесты зелёные.

<details>
<summary>Подсказка</summary>

Компилятор сначала сообщает о синтаксических ошибках и только после их исправления
показывает остальные. Поэтому ошибок три, а в первом запуске видна одна.
Фраза `but have Println` в сообщении — это подсказка компилятора, что имя написано
почти правильно.

</details>
