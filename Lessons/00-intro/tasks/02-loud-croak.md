# Задача 2. Жабку слышно с другого берега

## Контекст

Жабка квакает, но тихо: с другого берега пруда её не слышно.

## Что нужно

После обычного кваканья жабка квакает ещё раз — громко.

## Критерии приёмки

- [ ] При запуске жабка квакает дважды: сначала обычно, потом громко.
- [ ] Громкий вариант получен из обычного готовой функцией стандартной библиотеки,
      а не набран вручную.
- [ ] Обычное кваканье работает как раньше.
- [ ] `gofmt -l .` и `go vet ./...` ничего не выводят.
- [ ] Работа закоммичена и отправлена в GitHub. Сообщение коммита говорит, что сделано.

<details>
<summary>Подсказка</summary>

Громко — значит заглавными буквами. Подходящий пакет есть в таблице
«Стандартная библиотека: готовые пакеты» в уроке. Описание его функций можно найти
на pkg.go.dev или командой `go doc`.

</details>
