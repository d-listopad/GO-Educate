# Шаг 0. Настройка среды

На iPad нельзя установить Go, поэтому код пишется на облачном компьютере GitHub —
**Codespace**. Он открывается в Safari, в нём есть редактор кода VS Code. Всё вместе —
Go, редактор и его настройки — называют **средой** (environment).

Весь курс ты делаешь одну программу — «Пруд». Все её файлы в одной папке — **проект**
(project). Проект хранится на GitHub в **репозитории** (repository) `pond` — папке,
которая помнит прошлые версии файлов. В конце шага (20–30 минут) у тебя будут `pond`
и открытый Codespace.

## Что настроено и что меняется

| Что | Трогать? |
|---|---|
| `.devcontainer/devcontainer.json` — настройки среды | Нет. Если среда сломалась — Rebuild Container (покажем позже), а не правка файла |
| Codespace | Один на весь курс: открывать существующий, не создавать новый |
| Collaborators в Settings | Нет |
| `README.md` — описание проекта | Пока нет |

Про каждый новый файл урок скажет, можно ли его трогать.

## Перед началом

- iPad с клавиатурой; трекпад или мышь очень желательны: кнопки в редакторе мелкие.
- Safari, iPad горизонтально: на узком экране GitHub прячет кнопки.
- На скриншотах ищи кнопку по названию **жирным**: у тебя расположение может
  отличаться. Рамка — куда нажать, номера — порядок. `d-listopad` — логин преподавателя.

## 1. Свой репозиторий `pond`

1. Открой [github.com/new](https://github.com/new).
2. В **Repository name** набери `pond`. Под полем появится «pond is available».
3. В **Choose visibility** выбери **Private**: репозиторий видишь только ты и те, кого
   пригласишь.
4. Включи **Add README** (**On**) — описание проекта. Без него репозиторий пуст,
   и Codespace не создать.
5. Остальные поля (**Owner**, **Description**, **Start with a template**,
   **Add .gitignore**, **Add license**) не трогай. Нажми **Create repository**.

![Форма создания репозитория](images/01-new-repo.png)

*1 — имя `pond`, 2 — Private, 3 — Add README, 4 — Create repository.*

Откроется `pond` с меткой Private и файлом `README.md`. Часть имени после точки —
**расширение** (file extension): оно говорит, что внутри, как `.docx` у документа Word.
`.md` — текст с разметкой: заголовки, списки.

## 2. Преподаватель — в collaborators

Collaborator — человек с доступом к твоему репозиторию: преподаватель будет читать код
и оставлять замечания.

1. На странице `pond` открой **Settings** (если не видно — в меню **More** справа).

   ![Меню More со скрытой вкладкой Settings](images/02-settings.png)

   *1 — More, 2 — Settings.*

2. Слева выбери **Collaborators**. Если GitHub попросит пароль или код — введи.

   ![Страница Collaborators](images/03-collaborators.png)

   *1 — Collaborators, 2 — Add people.*

3. Нажми **Add people**, набери `d-listopad`, выбери его в списке и нажми
   **Add to repository**.

   ![Окно Add people](images/10-add-people.png)

   *1 — поле логина, 2 — Add to repository. Кадр снят из аккаунта преподавателя,
   поэтому под полем «Could not find…»; у тебя там будет строка `d-listopad`.*

В списке появится `d-listopad` с пометкой **Pending Invite** — приглашение ждёт
ответа преподавателя. Больше ничего делать не нужно.

## 3. Описание среды

Codespace собирается по файлу `.devcontainer/devcontainer.json` (папка, косая черта,
файл): какой Go поставить и какие дополнения включить. **Дополнение**
(extension) — программа, которая добавляет редактору умений, например подсветку Go;
не путай с расширением имени файла. Образец лежит в GO-Educate, его нужно скопировать.

1. На странице `pond` нажми **+** рядом с **Go to file** (или **Add file**)
   → **Create new file**.

   ![Меню добавления файла](images/04-add-file.png)

   *1 — кнопка +, 2 — Create new file.*

2. В поле имени набери `.devcontainer/devcontainer.json`. После косой черты GitHub
   сделает `.devcontainer` папкой, в поле останется `devcontainer.json`.
3. Открой [образец](../../.devcontainer/devcontainer.json) в новой вкладке (нажми
   и удерживай ссылку → **Открыть в новой вкладке**, чтобы не потерять набранное имя).
   Нажми **Copy raw file**, вернись к `pond` и вставь в поле текста файла (Cmd + V).

   ![Кнопка Copy raw file](images/11-copy-raw.png)

   *Copy raw file — между Raw и кнопкой скачивания.*

   ![Новый файл devcontainer.json](images/05-new-file.png)

   *1 — имя файла (`main` рядом — ветка, см. п. 4), 2 — вставленный текст,
   3 — Commit changes..., 4 — закрыть панель Marketplace, если она открылась.
   Мелкие подсказки под полем не трогай.*

   Что ты вставила (менять не нужно):

   | Строка | Что значит |
   |---|---|
   | `"image": "…go:1.26-trixie"` | Система с Go 1.26 |
   | `"extensions": ["golang.go"]` | Дополнение для Go: подсветка, подсказки, проверка кода |
   | `"editor.formatOnSave": true` | Cmd + S выравнивает код; автосохранение — нет |
   | `"files.autoSave": "afterDelay"` | Файл сохраняется сам через секунду после правки |
   | `"cpus": 2` | Два ядра процессора: на них бесплатно 60 часов в месяц |
   | Остальное | Название среды и служебные настройки |

4. Записать файл в репозиторий как новую версию — **commit** (подробно — позже).
   Нажми **Commit changes...**, в окне ничего не меняй: оставь **Commit directly to the
   main branch** (`main` — основная ветка, branch; ветки разберём позже) и нажми
   **Commit changes**.

   ![Окно Commit changes](images/06-commit.png)

   *1 — Commit directly to the main branch, 2 — Commit changes.*

Нажми `pond` в строке пути сверху — в списке появилась папка `.devcontainer`.

## 4. Время до автоостановки

Codespace без дела останавливается сам через 30 минут, и всё это время тратятся часы.
Поставь 15 минут. Сделай это до создания Codespace: настройка действует только
на Codespace, созданные после неё.

1. Аватарка справа вверху → **Settings** (настройки аккаунта, не репозитория).

   ![Меню аватарки](images/12-avatar-menu.png)

   *1 — аватарка, 2 — Settings. Серым закрыто имя владельца скриншота.*

2. Слева **Codespaces** → **Default idle timeout** = 15 → **Save**.

   ![Default idle timeout](images/13-idle-timeout.png)

   *Default idle timeout. Остальное на странице не трогай.*

## 5. Создание Codespace

На странице `pond`: **<> Code** → вкладка **Codespaces** → **Create codespace on main**.

![Меню Code, вкладка Codespaces](images/07-create-codespace.png)

*1 — Code, 2 — Codespaces, 3 — Create codespace on main. «paid for by» — часы идут
из твоего бесплатного лимита.*

1. Подожди 2–4 минуты, пока идёт сборка (справа внизу **Building codespace...**,
   слева **Opening Remote...**). Ничего не нажимай.

   ![Codespace собирается](images/08-building.png)

   *Уведомление о сборке.*

2. На вопрос **Do you trust the authors of the files in this folder?** нажми
   **Trust Folder & Continue**: это твой репозиторий. Без этого Codespace не даст
   запускать программы (Restricted Mode).
3. Закрой панель **Chat** справа крестиком: она пишет код за тебя, а учишься ты.

![Окно доверия папке и панель Chat](images/09-trust.png)

*1 — Trust Folder & Continue, 2 — закрыть Chat. Остальное в окне разберём в следующем
уроке.*

Codespace готов. Он один на весь курс: **Create codespace on main** больше не нажимай.

## 6. Safari на iPad

- **Весь экран под Safari**: редактору нужна вся ширина.
- **Иконка на экране «Домой»:** в открытом Codespace **Поделиться** → **На экран
  «Домой»**, и открывай через неё. В обычном Safari часть сочетаний клавиш срабатывает
  в браузере (Cmd + W закрывает вкладку). Попросит войти — войди тем же аккаунтом.
- **Английская раскладка** для кода (скобки `{}` есть только в ней): клавиша
  с глобусом или Ctrl + Пробел.

## 7. Лимиты

60 часов в месяц на двух ядрах, с твоего аккаунта. Остаток: аватарка → **Settings** →
**Billing and plans → Plans and usage**, раздел **Codespaces**.

Если не заходить в Codespace 30 дней, GitHub удалит его вместе с файлами, не записанными
в репозиторий. Сохранение (Cmd + S, автосохранение) хранит файл только в Codespace;
как записать работу в репозиторий — позже.

## Как проходить урок

Шаг можно делать в несколько заходов.

1. **Прочитать урок.** Незнакомое слово — в [словаре](../glossary.md).
2. **Набрать примеры руками** и запустить: так запоминаются правила записи кода.
3. **Ответить на «Проверь себя»**, потом раскрыть ответ (строка «Ответ»
   с треугольником). Не совпал — перечитать раздел.
4. **Сделать задачи** из папки `tasks/` в `pond`, по порядку. Раздел «Где менять» говорит,
   какие файлы трогать.
5. **Проверить критерии приёмки.** Флажки — список для себя, на GitHub не нажимаются.
6. **Записать работу в репозиторий и пройти разбор**: преподаватель оставит замечания,
   ты их исправишь. Как — покажем позже, справка — раздел [Git](../../Git/README.md).

**Если застряла:** прочитай сообщение об ошибке целиком и найди его в «Типичных
ошибках» урока. Не вышло за 20–30 минут — запиши, что пробовала, и спроси преподавателя.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Нет вкладки Codespaces в меню Code | Проверь, что вошла в свой аккаунт GitHub |
| Сборка висит больше 5 минут | Обнови страницу |
| Нажала Cancel в окне доверия | Нажми **Restricted Mode** внизу окна → **Trust** |
| Экран не такой, как описано | Напиши преподавателю, что видишь |
| Закончились 60 часов | Жди следующего месяца или спроси преподавателя |
