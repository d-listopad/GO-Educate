# Задача 1. Среда готова

## Что нужно

Пройти инструкцию [шага 0](../lesson.md) от начала до конца: у тебя есть свой
репозиторий `pond` и Codespace для него, преподаватель видит твой репозиторий.

## Критерии приёмки

- [ ] Репозиторий `pond` создан в твоём аккаунте, он приватный (метка **Private**
      рядом с именем).
- [ ] Преподаватель `d-listopad` приглашён в collaborators.
      Как проверить: **Settings → Collaborators** — логин в списке.
- [ ] В репозитории есть файл `.devcontainer/devcontainer.json`.
      Как проверить: на странице `pond` видна папка `.devcontainer`, внутри — файл.
- [ ] Для `pond` создан ровно один Codespace, и он открывается.
      Как проверить: [github.com/codespaces](https://github.com/codespaces) — в списке
      одна строка с `pond`.
