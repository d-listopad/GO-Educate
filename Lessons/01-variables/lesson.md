# Шаг 1. Переменные и типы

## Чему мы научимся

- Хранить значения в переменных и заменять их по ходу программы.
- Выбирать тип значения: целое число, дробное число, текст, ответ «да или нет».
- Создавать переменные двумя способами, `:=` и `var`, и понимать, когда какой нужен.
- Знать, что лежит в переменной, которой ничего не присвоили.
- Печатать значения внутри фразы с помощью `fmt.Printf`.

Для чего это нужно знать: программа из шага 0 печатает только то, что заранее написано
в кавычках. Настоящие программы работают с данными, которые появляются и меняются
во время работы: количество, цена, температура, ответ человека. Чтобы с такими данными
что-то делать, программе нужно место, где их хранить. Без него она может только
повторять готовый текст.

## Где применяется. Как часто используется

- Переменные — в каждой функции почти любой программы. Строка вида `x := ...` —
  одна из самых частых в Go-коде.
- `var` — реже: когда переменная должна начать с нулевого значения или когда она
  объявлена вне функции.
- Типы `int` и `string` — повседневно. `float64` — в измерениях и расчётах:
  температура, расстояние, координаты. `bool` — в условиях, они появятся в шаге 4.
- `fmt.Printf` — для вывода в терминал. Те же метки `%d`, `%s`, `%v` понимают
  и другие функции пакета `fmt`, например `fmt.Errorf` из шага 10.

Это повседневный материал: без переменных не обходится ни одна программа длиннее
нескольких строк.

## Объяснение материала

### Переменная

Программе часто нужно запомнить значение, чтобы обратиться к нему позже или заменить
его другим. Удобно представить коробочку с подписью: на подписи имя, внутри лежит
значение. По имени коробочку находят, а содержимое можно вынуть и положить новое.

**Переменная** (variable) — место в памяти компьютера, у которого есть имя и в котором
хранится одно значение. Память — то место, где программа держит свои данные, пока
работает; после завершения программы оно освобождается.

`main.go`
```go
package main

import "fmt"

func main() {
	count := 3
	fmt.Println(count)

	count = 5
	fmt.Println(count)
}
```

```
$ go run .
3
5
```

В этом файле две разные операции:

- `count := 3` — **объявление** (declaration): создать переменную `count` и сразу
  записать в неё значение `3`. Знак `:=` читается как «создать и записать».
- `count = 5` — **присваивание** (assignment): записать новое значение в переменную,
  которая уже существует. Старое значение `3` при этом теряется: переменная хранит
  одно значение, а не историю.

Важно понимать: знак `=` в Go — не равенство из математики. Запись `count = 5` означает
не «count равно 5», а действие: «вычислить то, что справа, и записать в переменную
слева». Поэтому порядок строк имеет значение: первый `Println` печатает `3`, второй —
`5`, хотя переменная одна.

Объявить переменную можно один раз. Присваивать ей новые значения — сколько угодно.

### Тип

Числа и текст устроены по-разному. С числами можно считать, с текстом нельзя:
`"3"` в кавычках — это символ, а не число три. Поэтому каждая переменная создаётся
под один вид значений. Это похоже на коробку определённой формы: в коробку для чисел
текст не положить.

**Тип** (type) — вид значений, которые может хранить переменная. Тип задаётся
при объявлении и больше не меняется. Четыре основных типа:

| Тип | Что хранит | Примеры значений |
|---|---|---|
| `int` | Целое число, в том числе отрицательное | `42`, `-7`, `0` |
| `float64` | Число с дробной частью | `3.14`, `-0.5`, `2.0` |
| `string` | Текст. В программировании его называют **строкой** | `"Привет"`, `""` |
| `bool` | Ответ «да или нет»: `true` (истина) или `false` (ложь) | `true`, `false` |

Дробная часть отделяется точкой, а не запятой: `3.14`. Название `bool` происходит
от логического типа (boolean), такие значения понадобятся в шаге 4 для условий.
Есть и другие числовые типы, например `int64` или `uint8`. Они нужны в специальных
случаях, в курсе достаточно `int` и `float64`.

При объявлении через `:=` тип не пишется. Компилятор определяет его сам по значению
справа: `3` — `int`, `3.0` — `float64`, `"3"` — `string`, `true` — `bool`.
Это называется **выводом типа** (type inference): тип выводится из значения.

Раз тип закреплён, записать в переменную значение другого типа нельзя:

Фрагмент:
```go
count := 3
count = "три" // ошибка: count хранит int, а "три" — строка
```

Компилятор не создаст исполняемый файл и сообщит об ошибке. Её текст разобран
в разделе «Типичные ошибки».

### Вывод значений: `fmt.Printf`

Часто значение нужно напечатать внутри фразы. `fmt.Println` печатает переданные
значения через пробел, но не позволяет управлять тем, как именно они выглядят.
Для этого есть `fmt.Printf`. Её удобно представить как бланк с пропусками: текст
бланка написан заранее, а в пропуски по порядку вписываются значения.

`main.go`
```go
package main

import "fmt"

func main() {
	city := "Казань"
	temp := 12

	fmt.Printf("%s: %d градусов\n", city, temp)
}
```

```
$ go run .
Казань: 12 градусов
```

Первое значение в скобках — **строка формата** (format string): текст с метками
на месте будущих значений. Метка начинается со знака `%`, в документации Go метки
называют **глаголами** (verbs). Значения после строки формата подставляются в метки
по порядку: `city` — в `%s`, `temp` — в `%d`.

`\n` в конце — два символа, которые означают один: переход на новую строку.
`fmt.Println` переходит на новую строку сам, `fmt.Printf` — только если в строке
формата есть `\n`.

| Глагол | Что печатает | Пример | Результат |
|---|---|---|---|
| `%d` | Целое число | `Printf("%d", 42)` | `42` |
| `%s` | Строку как есть | `Printf("%s", "Go")` | `Go` |
| `%q` | Строку в кавычках: видна даже пустая строка | `Printf("%q", "Go")` | `"Go"` |
| `%.2f` | Дробное число, два знака после точки | `Printf("%.2f", 3.14159)` | `3.14` |
| `%t` | `true` или `false` | `Printf("%t", true)` | `true` |
| `%v` | Любое значение в обычном виде | `Printf("%v", 42)` | `42` |
| `%T` | Тип значения | `Printf("%T", 3.0)` | `float64` |

В таблице `Printf` записана без `fmt.` для краткости, в коде префикс пакета нужен.
Число после точки в `%.2f` задаёт количество знаков: `%.1f` печатает один знак.

Глагол должен подходить к типу значения. Если передать строку в `%d`, программа
напечатает вместо числа `%!d(string=...)`. Команда `go vet ./...` из шага 0 находит
такие места заранее, ещё до запуска.

### `var` и нулевое значение

Кроме `:=`, переменную можно объявить словом `var`. Тогда тип пишется явно,
а значение можно не указывать:

Фрагмент:
```go
var count int
var price float64 = 3
```

Может показаться, что в переменной, которой ничего не присвоили, пусто или лежит что-то
случайное. В Go это не так: каждая переменная с момента объявления хранит значение.
Если его не указали, это **нулевое значение** (zero value) своего типа:

| Тип | Нулевое значение |
|---|---|
| `int` | `0` |
| `float64` | `0` |
| `string` | `""` — пустая строка, в ней нет ни одного символа |
| `bool` | `false` |

`main.go`
```go
package main

import "fmt"

func main() {
	var n int
	var x float64
	var s string
	var ok bool

	fmt.Printf("%d %v %q %t\n", n, x, s, ok)
}
```

```
$ go run .
0 0 "" false
```

Глагол `%q` здесь нужен, чтобы увидеть пустую строку: `%s` напечатал бы на её месте
ничего.

Когда какой способ выбирать:

- `:=` — когда значение известно сразу. Это основной способ внутри функций.
- `var x тип` — когда переменная должна начать с нулевого значения, например счётчик,
  который начинается с нуля.
- `var x тип = значение` — когда нужен тип, отличный от того, что вывел бы компилятор:
  `var price float64 = 3` хранит дробное число, хотя `3` само по себе — `int`.

### Почему количество и деньги не хранят во `float64`

`float64` хранит большинство дробных чисел не точно, а приблизительно. Компьютер
записывает числа в двоичной системе, где есть только цифры 0 и 1, и многие привычные
десятичные дроби в ней бесконечны. Так же в десятичной системе бесконечна дробь
одна третья: 0,333… Компьютер хранит конечное число цифр, и остаток отбрасывается.

`main.go`
```go
package main

import "fmt"

func main() {
	x := 0.1
	fmt.Printf("%.20f\n", x)
}
```

```
$ go run .
0.10000000000000000555
```

В переменной лежит не ровно одна десятая, а ближайшее число, которое помещается
в `float64`. При печати с малым числом знаков разница не видна, но в расчётах
она накапливается.

Поэтому правило:

- То, что считают штуками, хранится в `int`: людей, товаров, попыток. Половины
  штуки не бывает, и тип это гарантирует.
- Деньги хранятся в `int` в самых мелких единицах: 199 рублей 90 копеек —
  это `19990` копеек. Копейка не теряется ни в каких расчётах.
- `float64` — для измерений, где крошечная погрешность ничего не меняет:
  температура, расстояние, вес.

### Переменные вне функции

В A Tour of Go строки с `var` иногда стоят между `import` и `func main`:

Фрагмент:
```go
var total int

func main() {
	// ...
}
```

Такая переменная объявлена на уровне пакета, и её видят все функции пакета.
Вне функций разрешён только `var`, способ `:=` работает лишь внутри функций.
В курсе переменные объявляются внутри `main`: переменную, которую может изменить
любая функция, труднее отследить.

В той же Tour of Go встречается объявление нескольких переменных в одной строке:
`a, b := 1, 2`. Имена и значения перечисляются через запятую и сопоставляются
по порядку.

### Как принято в Go

**Нулевое значение полезно.** Переменная, объявленная через `var x int`, сразу готова
к работе, дописывать `= 0` не нужно. Нулевое значение — не «ещё не заполнено»,
а осмысленное начальное состояние: счётчик с нуля, пустая строка, «нет».

**`:=` внутри функций, `var` — когда нужно нулевое значение или особый тип.**
Это не правило компилятора, а договорённость: по способу объявления читатель видит
намерение автора.

**Имена в стиле MixedCaps.** Имя из нескольких слов пишется слитно, каждое следующее
слово — с заглавной буквы: `maxSize`, `itemCount`. Подчёркивания не используются:
не `max_size` и не `MAX_SIZE`. Заглавная буква в начале имени имеет особый смысл
(шаг 0: экспорт), поэтому внутри функций имена начинаются со строчной.

**Длина имени соответствует области, где оно используется.** Переменная, которая живёт
три строки, называется коротко: `i`, `n`, `s`. Переменная, к которой обращаются
по всей функции, называется полно: `total`, `price`. Длинное имя в трёх строках так же
мешает, как однобуквенное — в сорока.

**Количество и деньги — в целых числах.** `float64` только для измерений.

**Неиспользуемая переменная — ошибка.** Как и неиспользуемый импорт из шага 0:
объявленная, но нигде не прочитанная переменная — либо ошибка автора, либо мусор,
и компилятор не даёт ей остаться в коде.

### Типичные ошибки

| Сообщение | Причина | Исправление |
|---|---|---|
| `declared and not used: x` | Переменная объявлена, но её значение нигде не используется | Использовать переменную или удалить строку |
| `cannot use "три" (untyped string constant) as int value in assignment` | В переменную типа `int` записывается строка. `untyped string constant` — так компилятор называет текст, записанный прямо в коде | Записать значение того же типа, что у переменной |
| `no new variables on left side of :=` | `:=` применён к переменной, которая уже объявлена | Для нового значения использовать `=` |
| `undefined: count` | Присваивание через `=` переменной, которую не объявили, или опечатка в имени | Объявить через `:=` или исправить имя |
| `assignment mismatch: 1 variable but 2 values` | Дробная часть записана через запятую: `x := 3,5`. Компилятор видит два значения, `3` и `5` | Писать через точку: `3.5` |
| `syntax error: non-declaration statement outside function body` | `:=` использован вне функции | Перенести внутрь функции или объявить через `var` |
| `%!d(string=три)` в выводе | Глагол не подходит к типу значения | Подобрать глагол по таблице или использовать `%v` |
| `%!d(MISSING)` в выводе | Меток в строке формата больше, чем переданных значений | Передать недостающее значение |

Последние две строки — не сообщения компилятора: программа запускается и печатает
их вместо значения. Команда `go vet ./...` находит такие вызовы `Printf` заранее
и сообщает, например, `fmt.Printf format %d has arg "три" of wrong type string`.
