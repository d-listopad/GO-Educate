# Задание 2. Новая жабка

## Контекст

У Марфы появилась сестра. Она только что вылупилась: имени у неё ещё нет,
и в животе ни одной мухи. Чуть позже ей дают имя Квакуша, и она съедает
двух мух.

## Что сделать

В файле `main.go`:

1. Объяви переменные `name` и `flies` через `var`, не указывая значений.
2. Напечатай их через `fmt.Printf`. Имя печатается в кавычках, чтобы было видно
   пустую строку.
3. Присвой `name` значение `"Квакуша"`, а `flies` — значение `2`.
4. Напечатай их ещё раз той же строкой формата.

## Пример

```
$ go run .
Имя: "", мух: 0
Имя: "Квакуша", мух: 2
```

## Как проверить

В папке задания выполни:

```sh
go test
```

Готово, когда все тесты зелёные.

<details>
<summary>Подсказка</summary>

Переменная, объявленная через `var` без значения, хранит нулевое значение своего
типа. Строку в кавычках печатает глагол `%q`. Для присваивания новых значений
нужен знак `=`, а не `:=`: переменные уже объявлены.

</details>
