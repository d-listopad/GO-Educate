# Задание 3. Погода

## Контекст

Это задание не про жабок. Оно про выбор типа: в одной программе встречаются текст,
дробное число и ответ «да или нет».

## Что сделать

В файле `main.go` объяви через `:=` три переменные:

- `city` — город, `"Казань"`;
- `temp` — температура в градусах, `12.5`;
- `rain` — идёт ли дождь, `true`.

Напечатай две строки через `fmt.Printf`. В первой — значения переменных, температура
с одним знаком после точки. Во второй — типы этих переменных, которые вывел компилятор.

## Пример

```
$ go run .
Казань: 12.5 °C, дождь: true
Типы: string, float64, bool
```

## Как проверить

В папке задания выполни:

```sh
go test
```

Готово, когда все тесты зелёные.

<details>
<summary>Подсказка</summary>

Температура — измерение, поэтому для неё подходит `float64`, и печатается она
глаголом `%.1f`. Для `true` и `false` есть глагол `%t`. Тип любого значения печатает
`%T`; во второй строке не пиши названия типов вручную, а передай в `Printf` сами
переменные.

</details>
