# Задание 1. Жабка представляется

## Контекст

В шаге 0 жабка умела только квакать. Теперь у неё есть имя — Марфа — и в животе
три мухи. Эти данные будут меняться по ходу курса, поэтому их нужно хранить
в переменных, а не писать прямо в тексте.

## Что сделать

В файле `main.go` объяви две переменные:

- `name` — имя жабки, `"Марфа"`;
- `flies` — сколько мух у неё в животе, `3`.

Затем одной командой `fmt.Printf` напечатай фразу, подставив в неё обе переменные:

```
Ква! Я Марфа, во мне 3 мухи
```

Мухи считаются штуками: половины мухи не бывает. Подумай, какой тип должен быть
у `flies`.

## Пример

```
$ go run .
Ква! Я Марфа, во мне 3 мухи
```

## Как проверить

В папке задания выполни:

```sh
go test
```

Готово, когда все тесты зелёные.

<details>
<summary>Подсказка</summary>

Обе переменные объявляются через `:=`, тип компилятор выведет сам. В строке формата
нужны две метки: `%s` для имени и `%d` для числа. Не забудь `\n` в конце.

</details>
