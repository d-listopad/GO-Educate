# Lessons

Уроки по темам. Каждая тема — отдельная папка с номером и названием:

```
Lessons/
  00-intro/
    lesson.md   — текст урока
    tasks/      — задания к уроку, по папке на задание
  01-tema/
    lesson.md
    tasks/
```

Темы проходятся по порядку номеров. Задания проверяются командой `go test`
в папке задания.
