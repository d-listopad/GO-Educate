# Lessons

Уроки по темам. Каждая тема — отдельная папка с номером и названием:

```
Lessons/
  00-intro/
    lesson.md   — текст урока
    tasks/      — задачи к уроку, по файлу на задачу
  01-tema/
    lesson.md
    tasks/
```

Темы проходятся по порядку номеров. Задачи выполняются не здесь, а в твоём
репозитории `pond`: весь курс это одна программа «Пруд», и каждая задача добавляет
ей новую возможность. Задача описывает, что нужно сделать, и даёт критерии приёмки:
работа готова, когда выполнены все пункты.

Порядок работы с уроком — [Как проходить урок](../Introduction/How-to-study.md).
Все термины курса — в [словаре](glossary.md).
