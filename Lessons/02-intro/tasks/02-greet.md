# Задача 2. Жабка здоровается

## Контекст

Жабка квакает, но больше ничего не говорит. Пора поздороваться с тем, кто запустил
программу.

## Что нужно

После кваканья программа печатает приветствие отдельной строкой. Текст выбери сама.

## Где менять

Меняется `main.go` в корне `pond`. Остальное не трогаем.

## Git: что изменилось

Команды — в корне `pond`. Как читать их ответы — раздел Git,
[1. Репозиторий и коммит](../../../Git/01-repository-and-commit.md).

- `git diff` до `git add .` показывает изменённые строки: добавленные — с `+`,
  удалённые — с `-`. Если внизу появилось `:`, листай пробелом, выход — `q`.
- `git log --oneline` после коммита показывает историю.

## Критерии приёмки

- [ ] При запуске жабка сначала квакает, затем здоровается, каждая фраза — на своей
      строке.
- [ ] `gofmt -l .` и `go vet ./...` ничего не выводят.
- [ ] Перед коммитом ты посмотрела `git diff`: в нём одна новая строка с `+`.
- [ ] Работа сохранена коммитом и отправлена в GitHub (push).
      Как проверить: `git log --oneline` — сверху два твоих коммита, ниже два коммита
      из шага 0, их создал GitHub.

## Вопрос к разбору

Что напечатает программа, если поменять местами строку с кваканьем и строку
с приветствием, и почему?

Ответ — комментарием к своему коммиту на GitHub (Git,
[2. GitHub: push и pull](../../../Git/02-github-push-pull.md), «Комментарии к коммиту»).
