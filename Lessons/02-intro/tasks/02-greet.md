# Задача 2. Жабка здоровается

## Контекст

Жабка квакает, но больше ничего не говорит. Пора ей поздороваться с тем, кто
запустил программу.

## Что нужно

После кваканья жабка здоровается: программа печатает приветствие отдельной строкой.
Текст приветствия выбери сама.

## Где менять

Меняется `main.go` в корне `pond`. `go.mod`, `.gitignore`, `try/` и `.devcontainer`
не трогаем. `README.md` можно не менять: запускается программа так же.

## Git: что изменилось

Перед коммитом посмотри, что именно войдёт в него. Все команды — в корне `pond`.

- `git status` покажет изменённые файлы.
- `git diff` покажет изменённые строки: добавленные — с `+`, удалённые — с `-`.
  Набирай его до `git add .`: после отметки он ничего не покажет. Если ответ не
  помещается в терминал, внизу появится `:` — листай пробелом, выход — клавиша `q`.
  Ctrl + C здесь не помогает.
- После коммита `git log --oneline` покажет историю проекта.

Как читать их ответы — раздел Git,
[1. Репозиторий и коммит](../../../Git/01-repository-and-commit.md).

## Критерии приёмки

- [ ] При запуске жабка сначала квакает, затем здоровается, каждая фраза — на своей
      строке.
- [ ] Кваканье работает как раньше.
- [ ] `gofmt -l .` и `go vet ./...` ничего не выводят.
- [ ] Перед коммитом ты посмотрела `git diff`: в нём одна новая строка с `+`.
- [ ] Работа сохранена коммитом и отправлена в GitHub (push). Сообщение коммита
      говорит, что сделано.
      Как проверить: `git log --oneline` показывает сверху два твоих коммита — новый
      и из задачи 1. Ниже — два коммита из шага 0 (Initial commit и Create
      devcontainer.json): их создал GitHub, когда ты создавала репозиторий и файл.
