# Словарь терминов

Все термины курса в одном месте: точное определение и шаг, где термин разобран
подробно. Если слово в уроке забылось — оно здесь.

| Термин | English | Что это | Шаг |
|---|---|---|---|
| Git | git | Программа, которая ведёт историю изменений проекта | 0 |
| MixedCaps | MixedCaps | Стиль имён: слова слитно, каждое следующее с заглавной — `maxSize` | 1 |
| Pull | pull | Получение новых коммитов из удалённого репозитория: `git pull` | 0 |
| Pull request | pull request | Запрос на GitHub влить ветку в `main`; в нём проходит разбор кода | 1 |
| Push | push | Отправка новых коммитов в удалённый репозиторий: `git push` | 0 |
| Библиотека | library | Пакет с готовыми функциями для других пакетов; сам по себе не запускается | 0 |
| Ветка | branch | Отдельная линия истории коммитов; основная ветка — `main` | 1 |
| Вывод типа | type inference | Компилятор определяет тип переменной по значению справа от `:=` | 1 |
| Глагол | verb | Метка в строке формата, начинается с `%`: `%d`, `%s`, `%q`, `%v` | 1 |
| Импорт | import | Подключение пакета в файле строкой `import` | 0 |
| Индекс | staging area | Изменения, отмеченные командой `git add` для следующего коммита | 0 |
| Исполняемый файл | executable | Файл с машинным кодом, который компьютер может запустить | 0 |
| Исходный код | source code | Текст программы, который пишет человек | 0 |
| Коммит | commit | Сохранённое в git состояние файлов проекта с сообщением, что изменилось | 0 |
| Компилятор | compiler | Программа, которая проверяет исходный код и создаёт из него исполняемый файл | 0 |
| Машинный код | machine code | Команды, которые выполняет процессор компьютера | 0 |
| Модуль | module | Весь проект; его корень отмечает файл `go.mod` | 0 |
| Нулевое значение | zero value | Значение переменной, которой ничего не присвоили: `0`, `""`, `false` | 1 |
| Объявление | declaration | Создание переменной: `x := 3` или `var x int` | 1 |
| Пакет | package | Папка с файлами `.go`, у которых одинаковая строка `package имя` | 0 |
| Переменная | variable | Место в памяти с именем, где хранится одно значение | 1 |
| Присваивание | assignment | Запись нового значения в существующую переменную: `x = 5` | 1 |
| Пространство имён | namespace | Область, внутри которой каждое имя означает ровно одну вещь; в Go это пакет | 0 |
| Путь импорта | import path | Адрес пакета в кавычках после `import`: `"fmt"`, `"math/rand"` | 0 |
| Репозиторий | repository | Папка проекта вместе с историей коммитов | 0 |
| Синтаксическая ошибка | syntax error | Нарушена сама запись кода: не хватает скобки или кавычки | 0 |
| Слияние | merge | Перенос коммитов ветки в другую ветку, обычно в `main` | 1 |
| Смысловая ошибка | semantic error | Запись правильная, но смысл не сходится: имени нет, пакет не используется | 0 |
| Стандартная библиотека | standard library | Набор пакетов, который поставляется вместе с Go | 0 |
| Строка | string | Текст; тип `string` | 1 |
| Строка формата | format string | Первый аргумент `Printf`: текст с глаголами на месте значений | 1 |
| Строковый литерал | string literal | Строка, записанная прямо в коде в двойных кавычках | 0 |
| Тип | type | Вид значений, которые может хранить переменная: `int`, `float64`, `string`, `bool` | 1 |
| Точка входа | entry point | Функция `main` в пакете `main`, с неё начинается выполнение | 0 |
| Удалённый репозиторий | remote repository | Копия репозитория на сервере, для `pond` — на GitHub; по умолчанию называется `origin` | 0 |
| Форматировщик | formatter | Программа `gofmt`, приводит отступы и пробелы к единому виду | 0 |
| Экспортируемое имя | exported name | Имя с заглавной буквы, видное из других пакетов | 0 |
