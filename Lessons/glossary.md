# Словарь терминов

Все термины курса в одном месте: точное определение и шаг, где термин разобран
подробно. Если слово в уроке забылось — оно здесь.

| Термин | English | Что это | Шаг |
|---|---|---|---|
| Codespace | Codespace | Компьютер в облаке GitHub с редактором VS Code, открывается в браузере | 0 |
| Collaborator | collaborator | Человек, которому дан доступ к твоему репозиторию на GitHub | 0 |
| Git | git | Программа, которая ведёт историю изменений проекта | 1 |
| MixedCaps | MixedCaps | Стиль имён: слова слитно, каждое следующее с заглавной — *maxSize* | 3 |
| Pull | pull | Получение новых коммитов из удалённого репозитория: *git pull* | 2 |
| Pull request | pull request | Запрос на GitHub влить ветку в *main*; в нём проходит разбор кода | 3 |
| Push | push | Отправка новых коммитов в удалённый репозиторий: *git push* | 2 |
| Ветка | branch | Отдельная линия истории коммитов; основная ветка — *main* | 3 |
| Возвращать значение | return value | Функция отдаёт результат туда, где её вызвали: *strconv.Atoi("42")* возвращает число *42* и ошибку | 5 |
| Вывод типа | type inference | Компилятор определяет тип переменной по значению справа от *:=* | 3 |
| Вызов функции | function call | Выполнение функции по её имени: *fmt.Println("текст")* | 2 |
| Глагол | verb | Метка в строке формата, начинается с *%*: *%d*, *%s*, *%q*, *%v* | 3 |
| Декремент | decrement | Уменьшение переменной на единицу: *x--* | 4 |
| Импорт | import | Подключение пакета в файле строкой *import* | 2 |
| Индекс | staging area | Изменения, отмеченные командой *git add* для следующего коммита | 2 |
| Инкремент | increment | Увеличение переменной на единицу: *x++* | 4 |
| Команда | command | Строка, которую набирают в терминале и выполняют нажатием Enter | 1 |
| Комментарий | comment | Текст от *//* до конца строки: пояснение для человека, компилятор его пропускает | 3 |
| Коммит | commit | Сохранённое в git состояние файлов проекта с сообщением, что изменилось | 0 |
| Компилятор | compiler | Программа-переводчик: проверяет текст программы и переводит его в команды для компьютера. Запускается командой *go run* | 2 |
| Константа | constant | Имя для значения, которое задаётся один раз и не меняется: *const limit = 10* | 4 |
| Корень проекта | project root | Самая верхняя папка проекта, в которой лежит всё остальное | 1 |
| Модуль | module | Весь проект; его корень отмечает файл *go.mod* | 2 |
| Нулевое значение | zero value | Значение переменной, которой ничего не присвоили: *0*, *""*, *false* | 3 |
| Объявление | declaration | Создание имени в коде: функции «func main() {…}», переменной *x := 3* | 2 |
| Оператор | operator | Значок, который вычисляет новое значение из других: *+*, *-*, «*», */*, *%* | 4 |
| Ошибка | error | Значение, которое сообщает, что у функции не вышло; *nil* — ошибки нет. Не путать с ошибкой компилятора | 5 |
| Пакет | package | Файлы *.go* одной папки с одинаковой первой строкой *package имя* | 2 |
| Паника | panic | Аварийная остановка программы во время работы, например при делении на ноль | 4 |
| Переменная | variable | Имя, под которым программа хранит одно значение | 3 |
| Переменная окружения | environment variable | Имя и текстовое значение, заданные при запуске программы снаружи: *COUNT=21 go run .*; читается через *os.Getenv* | 5 |
| Преобразование типа | type conversion | Получение значения другого типа: *float64(n)* | 4 |
| Присваивание | assignment | Запись нового значения в существующую переменную: *x = 5* | 3 |
| Проект | project | Все файлы одной программы, сложенные в одну папку; для Go — модуль | 0 |
| Пустой идентификатор | blank identifier | «_» на месте имени: значение отбрасывается без сохранения | 5 |
| Путь | path | Адрес папки или файла: имена папок через */*, например */workspaces/pond* | 1 |
| Расширение редактора | extension | Программа, которая добавляет редактору возможности, например поддержку Go; не путать с расширением имени файла | 0 |
| Расширение файла | file extension | Часть имени файла после последней точки, говорит, что внутри: *.docx*, *.go* | 0 |
| Редактор кода | code editor | Программа для написания кода: подсвечивает слова, показывает ошибки; в курсе — VS Code | 1 |
| Репозиторий | repository | Папка проекта вместе со всеми прошлыми версиями файлов (историей коммитов); есть на GitHub и копией в Codespace | 0 |
| Слияние | merge | Перенос коммитов ветки в другую ветку, обычно в *main* | 3 |
| Составное присваивание | compound assignment | Изменение переменной на основе её значения: *x += 5* значит *x = x + 5* | 4 |
| Среда | environment | Go, редактор и его настройки в Codespace; не путать с переменной окружения | 0 |
| Стандартная библиотека | standard library | Набор пакетов, который поставляется вместе с Go | 2 |
| Строка | string | Текст; тип *string* | 3 |
| Строка приглашения | prompt | Строка в терминале, после которой набирают команду; показывает, в какой папке она выполнится | 1 |
| Строка формата | format string | Первый аргумент *Printf*: текст с глаголами на месте значений | 3 |
| Строковый литерал | string literal | Строка, записанная прямо в коде в двойных кавычках | 2 |
| Терминал | terminal | Окно, где компьютеру дают команды текстом и читают его ответы | 1 |
| Тип | type | Вид значений, которые может хранить переменная: *int*, *float64*, *string*, *bool* | 3 |
| Удалённый репозиторий | remote repository | Копия репозитория на сервере, для *pond* — на GitHub; по умолчанию называется *origin* | 2 |
| Функция | function | Несколько действий, собранных вместе под одним именем; выполняется при вызове | 2 |
| Экспортируемое имя | exported name | Имя с заглавной буквы, видное из других пакетов | 2 |
