# Задача 1. Рабочее место готово

## Что нужно

Попробовать руками всё, что показано в уроке, и завести папку для примеров из уроков.

Примеры из уроков ты будешь набирать и запускать отдельно от своей программы.
Сама программа «Пруд» с шага 2 будет лежать прямо в корне `pond`, а примеры —
в папке `try`. Создай её так, как показано в уроке:

1. **Папка.** В Explorer нажми на заголовок `pond`, затем **New Folder...**, набери
   `try` и нажми Enter. Это ты делаешь руками, через интерфейс.
2. **Отметка, что в `try` будет код на Go.** Её ставит команда: она создаёт в `try`
   служебный файл `go.mod`. Проверь, что строка приглашения кончается
   на `/workspaces/pond`, и набери по очереди, нажимая Enter после каждой строки:

   ```sh
   cd try
   go mod init try
   ```

   - `cd` (change directory) — перейти в папку. После неё строка приглашения кончается
     на `/workspaces/pond/try`: терминал теперь в папке `try`.
   - `go mod init try` создаёт в этой папке файл `go.mod`. Слово `try` в конце — имя,
     под которым Go будет знать эти примеры; набери именно так. Команда ответит
     `go: creating new go.mod: module try` — значит, всё получилось. Файл появится
     в Explorer внутри `try`. Открыть и посмотреть его можно, править руками — нет:
     его меняют только команды `go`. Что в нём написано, разберём в шаге 2.

3. **Чтобы примеры не попали в историю версий.** Через git (о нём — в уроке, раздел
   «Activity Bar») ты будешь записывать в историю только свою программу, а не примеры. Для этого
   в корне `pond` нужен файл `.gitignore` — список того, что git не записывает. Имя
   должно быть ровно `.gitignore`, с точкой в начале: git ищет файл с этим именем.
   В Explorer нажми на заголовок `pond`, затем **New File...**, набери `.gitignore`
   и нажми Enter. В открывшийся файл напиши одну строку:

   ```
   try/
   ```

   `try/` значит «папку `try` целиком»: косая черта в конце указывает на папку. Сам
   файл сохранится, как любой другой; git просто не будет записывать `try` в историю.
   Как это работает, увидишь в шаге 2.

4. **Вернуть терминал в корень.** Набери `cd ..` — две точки значат «на папку выше».
   Строка приглашения снова кончится на `/workspaces/pond`: в шаге 2 команды
   выполняются отсюда.

5. **Попробовать файлы.** Создай в `pond` пробный файл и папку, открой файл, закрой
   его крестиком, переименуй и удали — как в уроке. Если меню правого клика
   не открывается, то же делается командами в терминале (в корне `pond`):

   ```sh
   mv hello.go hi.go
   rm hi.go
   rm -r demo
   ```

   `mv` (move) переименовывает: старое имя, потом новое. `rm` (remove) удаляет файл,
   `rm -r` — папку со всем, что в ней. Удалённое так не вернуть, поэтому проверяй имя
   перед Enter.

## Где менять

В `pond` появляются папка `try` и файл `.gitignore`. `.gitignore` больше не трогаешь.
В папку `try` дальше добавляешь примеры из уроков, а `go.mod` в ней не трогаешь.
`.devcontainer` и `README.md` не трогаем.

## Критерии приёмки

- [ ] `go version` в терминале отвечает версией Go.
- [ ] В `pond` есть папка `try`, в ней файл `go.mod`.
      Как проверить: в Explorer раскрой `try` — внутри `go.mod`.
- [ ] В корне `pond` есть `.gitignore` со строкой `try/`.
- [ ] Пробные файл и папка созданы, переименованы и удалены.
      Как проверить: в Explorer только `.devcontainer`, `try`, `.gitignore` и `README.md`.
- [ ] Ты знаешь, как открыть палитру команд и остановить Codespace, и остановила его
      в конце занятия.

Сохранять в git и отправлять в GitHub в этом шаге не нужно, разбора нет: это начнётся
в шаге 2. Проверь себя по критериям сама.
