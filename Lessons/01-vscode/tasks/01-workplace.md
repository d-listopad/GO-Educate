# Задача 1. Рабочее место готово

## Что нужно

Попробовать руками всё, что показано в уроке, и завести папку для примеров из уроков.

Примеры из уроков ты будешь набирать и запускать отдельно от кода своей программы.
Для них нужна папка `try` в `pond`. Создай её так, как показано в уроке:

1. **Папка.** В Explorer нажми на заголовок `pond`, затем **New Folder...**, набери
   `try` и нажми Enter. Это ты делаешь руками, через интерфейс.
2. **Проект на Go внутри папки.** Это делается командой. В терминале набери по очереди,
   нажимая Enter после каждой строки:

   ```sh
   cd try
   go mod init try
   ```

   `cd` (change directory) — перейти в папку: после неё строка приглашения кончается
   на `/workspaces/pond/try`, терминал теперь в папке `try`. `go mod init try` создаёт
   в этой папке файл `go.mod` — он появится в Explorer внутри `try`. Пока это ритуал,
   что он значит, разберём в шаге 2.

3. **Чтобы примеры не попали в программу.** Через git ты будешь сохранять только
   свою программу, а не примеры. Для этого в корне `pond` нужен файл `.gitignore` —
   список того, что git не сохраняет. В Explorer нажми на заголовок `pond`, затем
   **New File...**, набери `.gitignore` (с точкой в начале) и нажми Enter. В открывшийся
   файл напиши одну строку:

   ```
   try/
   ```

   Это ты делаешь руками. Сохранять не нужно, автосохранение включено. Как это работает,
   увидишь в шаге 2, когда будешь сохранять программу в git.

Чтобы вернуться терминалом в корень проекта, набери `cd ..` — две точки значат
«на папку выше». Строка приглашения снова кончится на `/workspaces/pond`.

## Где менять

В `pond` появляются папка `try` и файл `.gitignore`, дальше они не трогаются: в `try`
ты только добавляешь и правишь примеры. `.devcontainer` и `README.md` не трогаем.
Всё остальное, что ты создашь в Explorer для пробы, удали в конце.

## Критерии приёмки

- [ ] `go version` в терминале отвечает версией Go.
- [ ] В `pond` есть папка `try`, в ней файл `go.mod`.
      Как проверить: в Explorer раскрой `try` — внутри `go.mod`.
- [ ] В корне `pond` есть `.gitignore` со строкой `try/`.
- [ ] Через Explorer ты создала пробный файл и папку, открыла файл, закрыла его
      крестиком, переименовала и удалила.
      Как проверить: в Explorer только `.devcontainer`, `try`, `.gitignore` и `README.md`.
- [ ] Ты знаешь, как открыть палитру команд и остановить Codespace, и остановила его
      в конце занятия.
