# Шаг 1. Редактор VS Code

## В прошлом уроке

Ты создала репозиторий `pond` с описанием среды `.devcontainer` и открыла Codespace.
Среда настроена и больше не меняется; Codespace на весь курс один — его открывают,
а не создают заново.

## Что такое редактор кода

Программа на Go — текст в файлах. Пишут его в **редакторе кода** (code editor):
он подсвечивает слова, показывает ошибки и расставляет отступы. У нас это **VS Code** —
окно Codespace: через него ты правишь файлы облачного компьютера и даёшь ему команды.

Красная рамка на скриншотах — куда смотреть или нажимать.

## Окно целиком

![Окно VS Code в Codespace](images/01-window.png)

1. **Activity Bar** — полоска иконок слева. Переключает панель справа от неё.
2. **Explorer** — файлы и папки проекта: сейчас `.devcontainer` и `README.md`.
   Сверху — `pond` и в скобках имя твоего Codespace (его придумал GitHub, у тебя
   другие слова).
3. **Редактор** (editor) — открытые файлы, каждый во вкладке. При первом запуске
   Codespace сам открыл `README.md` как просмотр **[Preview]**; из Explorer файл
   открывается как текст. README пока не правим.
4. **Panel** — нижняя панель, из её вкладок нужна только **Terminal**. Приветствие
   Codespaces в ней можно не читать.
5. **Status Bar** — строка внизу, слева имя Codespace.

Поиск сверху, иконки справа вверху, Outline и Timeline не нужны. Файлы в Codespace —
копия репозитория `pond`; изменения попадут на GitHub, только когда ты их отправишь
(разберём позже).

## Сочетания клавиш

| Сочетание | Действие |
|---|---|
| Cmd + Shift + P | Палитра команд |
| Cmd + S | Сохранить файл и выровнять код |
| Ctrl + ` | Показать / скрыть терминал (клавиша слева от «1») |
| Cmd + B | Показать / скрыть Explorer, если он пропал |
| Ctrl + C в терминале | Остановить команду |
| Cmd + W | **Не нажимать** — закрывает вкладку Safari |

## Activity Bar: какие иконки нужны

![Иконки Activity Bar](images/02-activity-bar.png)

1. **☰** — главное меню, как «Файл, Правка…» в обычных программах.
2. **Explorer** — вернуть панель файлов.
3. **Source Control** — git кнопками. **Git** — программа, которая хранит историю
   версий файлов. В курсе git — командами в терминале, эту панель не используем.
   Синяя цифра на иконке действий не требует.
4. **Extensions** — дополнения редактора (поддержка Go), поставились сами,
   не меняй.

Остальные иконки не нужны.

## Файлы и папки

### Создать файл

Новый файл попадает в папку, выделенную в Explorer (строка с фоном), или в папку
выделенного файла. Верхняя папка проекта — **корень проекта** (project root), у тебя
`pond`. Чтобы создать файл в корне, сначала нажми на пустое место под списком файлов.

Нажми на заголовок `pond` (или наведи курсор) — справа появятся кнопки. Если дерево
свернулось, нажми на заголовок ещё раз.

![Кнопки Explorer](images/03-explorer-buttons.png)

1. **New File...** — создать файл.
2. **New Folder...** — создать папку.

Нажми **New File...**, набери `hello.go` и нажми Enter (Escape — отмена). `.go` —
расширение файлов с кодом на Go.

![Поле имени нового файла](images/04-new-file-name.png)

Файл появится в Explorer (1) и откроется во вкладке редактора (2).

![Новый файл открыт](images/05-file-open.png)

**U** — git ещё не записал файл в историю. Красное имя — пустой файл не похож
на программу. Generate code — подсказка, не обращай внимания.

### Создать папку

Кнопка **New Folder...**, имя `demo`, Enter.

![Поле имени новой папки](images/06-new-folder.png)

### Переименовать и удалить

Правый клик по файлу или папке в Explorer (на iPad — двумя пальцами по трекпаду
или долгое нажатие пальцем) открывает меню:

- **Rename...** — исправь имя и нажми Enter.
- **Delete** — подтверди **Delete** в окне. Удалённое не вернуть.

Переименуй `hello.go` в `hi.go`, затем удали `hi.go` и `demo`. Если меню
не открывается — в терминале (раздел «Терминал»):

```sh
mv hello.go hi.go
rm hi.go
rm -r demo
```

`mv` переименовывает, `rm` удаляет файл, `rm -r` — папку. При успехе ответа нет.

## Редактор и вкладки

Файл открывается нажатием в Explorer и сохраняется сам через секунду после правки.
Но в коде нажимай **Cmd + S**: так редактор ещё и выровняет отступы,
автосохранение этого не делает.

**Закрыть файл** — крестик на вкладке; файл не удаляется. Не Cmd + W: если окно
Codespace закрылось, открой его снова («Как закончить занятие»), файлы на месте.

![Крестик на вкладке файла](images/07-tab-close.png)

## Терминал

Компьютеру можно давать команды текстом: набираешь строку, нажимаешь Enter, он
выполняет и печатает ответ — как переписка в чате. Окно для этого — **терминал**
(terminal), набранная строка — **команда** (command). В курсе программу запускают,
проверяют и записывают в git командами.

Терминал — вкладка **Terminal** в нижней панели. Если панели нет — Ctrl + ` или
**☰ → Terminal → New Terminal**.

![Меню Terminal](images/08-menu-terminal.png)

### Куда набирать

![Терминал](images/09-prompt.png)

1. Вкладка **Terminal**.
2. Строка приглашения (prompt): `@логин → /workspaces/pond (main) $`.
   - `@логин` — твой логин GitHub.
   - `/workspaces/pond` — **путь** (path) к папке, где выполнится команда: имена
     папок через `/` от самой верхней. Explorer показывает только `pond`, папку
     `workspaces` над ней не видно.
   - `main` — основная ветка (шаг 0).
   - `$` — «жду команду».

   Кружок слева и надпись `bash` справа не важны.

Нажми на терминал, набери команду после `$` и нажми Enter. В уроках команды пишутся
без приглашения. Вставка — Cmd + V; если Safari спросит доступ к буферу — разреши.

### Первая команда

```sh
go version
```

Ответ — `go version go1.26.x linux/amd64` с цифрой вместо `x`. Значит, Go работает.

![Ответ на go version](images/10-go-version.png)

*Справа — два терминала: так бывает после лишнего New Terminal. Лишний закрывается
корзиной у его строки (наведи или нажми на строку).*

![Корзина у строки терминала](images/16-terminal-trash.png)

Пока команда выполняется, `$` нет; если она не заканчивается — Ctrl + C (не Cmd).

## Палитра команд

**Cmd + Shift + P** открывает сверху поле с `>`. Набери после `>` часть названия
действия, выбери его в списке, Enter. `>` не стирай: без него поле ищет файлы.

![Палитра команд](images/11-palette.png)

*⌘W справа от команды не нажимай.*

| Команда | Что делает |
|---|---|
| **View: Close Editor** | Закрыть файл, если крестик не виден |
| **Codespaces: Stop Current Codespace** | Остановить Codespace |
| **Codespaces: Rebuild Container** | Собрать сломанную среду заново; файлы остаются |

После Rebuild Container нажми зелёную **Rebuild**, не **Full Rebuild**.

![Окно Rebuild Container](images/17-rebuild.png)

## Что здесь трогать не нужно

![Source Control](images/12-source-control.png)

*1 — Source Control, 2 — Commit, не нажимай. Внизу, в Graph, — коммиты из шага 0.
Серым закрыто имя владельца скриншота.*

- **Chat** и подсказки вроде Generate code: код пишешь сама.
- Уведомления справа внизу закрывай крестиком. Кроме уведомления Go с кнопкой
  **Install** или **Install All** — её нажми.

## Как закончить занятие

Codespace остановится сам через 15 минут без действий, но лучше сразу:
**Cmd + Shift + P → Codespaces: Stop Current Codespace**.

![Остановка Codespace](images/13-stop.png)

Появится экран **Codespace is stopped**, окно можно закрыть.

![Codespace остановлен](images/15-stopped.png)

**Открыть снова:** [github.com/codespaces](https://github.com/codespaces) → нажми
на имя своего Codespace (те же слова, что в Status Bar). **New codespace** не нажимай.

![Список Codespaces](images/14-codespaces-list.png)

*1 — имя Codespace, 2 — New codespace, не нажимай.*

Файлы хранятся, пока Codespace не удалён: через 30 дней без входа (шаг 0).

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `go: command not found` | Палитра → **Codespaces: Rebuild Container** |
| Внизу надпись **Restricted Mode** | Нажми на неё и выбери **Trust** |
| Экран выглядит не так, как здесь | Напиши преподавателю, что видишь |
