# Шаг 3. Переменные и типы

## В прошлом уроке

Мы разобрали файл на Go (`package main`, `import "fmt"`, `func main`), запустили его
`go run .` и проверили `gofmt` и `go vet`. Код по-прежнему пишется в `main.go`,
`go.mod` руками не трогается. Пока программа печатает только текст в кавычках;
чтобы работать с данными, которые меняются, нужны переменные.

## Чему мы научимся

- Хранить значения в переменных и заменять их.
- Различать типы: целое число, дробное число, текст, «да или нет».
- Объявлять переменные через `:=` и `var`.
- Печатать значения внутри фразы через `fmt.Printf`.

Программе нужно где-то хранить данные, которые меняются во время работы.

## Где применяется. Как часто используется

Переменные и `:=` — в каждой функции; `var` — реже. `int` и `string` — повседневно,
`float64` — в расчётах, `bool` — в проверках «да или нет».

## Объяснение материала

Под каждым примером — что он печатает.

### Переменная

**Переменная** (variable) — имя, под которым программа хранит одно значение. Его можно
прочитать и заменить другим.

```go
package main

import "fmt"

func main() {
	count := 3
	fmt.Println(count)

	count = 5
	fmt.Println(count)
}
```

```
$ go run .
3
5
```

![Объявление и присваивание в программе](images/01-count.png)

*1 — объявление, 2 — присваивание, 3 — вывод. M у вкладки — файл изменён после коммита.*

- `count := 3` — **объявление** (declaration): создать переменную и записать в неё `3`.
  Делается один раз.
- `count = 5` — **присваивание** (assignment): записать новое значение в существующую
  переменную. Старое `3` теряется. Присваивать можно сколько угодно.

`=` — не равенство, а действие «записать значение справа в переменную слева»; строки
выполняются по порядку, поэтому первый `Println` печатает `3`. Имя без кавычек
печатает значение переменной, `"count"` в кавычках — само слово.

### Тип

| Тип | Что хранит | Примеры значений |
|---|---|---|
| `int` | Целое число | `42`, `-7`, `0` |
| `float64` | Число с дробной частью, через точку | `3.14`, `-0.5`, `2.0` |
| `string` | Текст, его называют **строкой** | `"Привет"`, `""` — пустая строка |
| `bool` | `true` (да) или `false` (нет) | `true`, `false` |

**Тип** (type) — вид значений, которые хранит переменная. Он задаётся при объявлении
и не меняется, поэтому компилятор до запуска проверяет, что с переменной делают
допустимое: `"3"` — текст, считать с ним нельзя. Линию в файле урок называет
«строка кода», чтобы не путать со строкой-текстом.

При `:=` тип не пишется: компилятор выводит его из значения (type inference): `3` —
`int`, `3.0` — `float64`, `"3"` — `string`, `true` — `bool`.

Записать в переменную значение другого типа нельзя:

Фрагмент:
```go
count = "три" // ошибка: count хранит int
```

Текст после `//` до конца строки кода — **комментарий** (comment): пояснение для
человека, компилятор его пропускает.

### Вывод значений: `fmt.Printf`

`fmt.Printf` печатает фразу, в которую подставлены значения.

```go
package main

import "fmt"

func main() {
	city := "Казань"
	temp := 12

	fmt.Printf("%s: %d градусов\n", city, temp)
}
```

```
$ go run .
Казань: 12 градусов
```

![Printf: строка формата и значения](images/02-printf.png)

*1 — `%s` и `city`, 2 — `%d` и `temp`, 3 — `\n`, 4 — вывод.*

Первое значение в скобках — **строка формата** (format string): текст с метками `%`,
их называют **глаголами** (verb). Значения после неё подставляются в глаголы по порядку.
`\n` — переход на новую строку: `Println` переходит сам, `Printf` — только по `\n`.

| Глагол | Что печатает | Пример | Результат |
|---|---|---|---|
| `%d` | Целое число | `Printf("%d", 42)` | `42` |
| `%s` | Строку как есть | `Printf("%s", "Go")` | `Go` |
| `%q` | Строку в кавычках, видна и пустая | `Printf("%q", "Go")` | `"Go"` |
| `%v` | Любое значение | `Printf("%v", 3.5)` | `3.5` |
| `%T` | Тип значения | `Printf("%T", 3)` | `int` |

Глагол должен подходить к типу значения.

### `var` и нулевое значение

| Тип | Нулевое значение |
|---|---|
| `int` | `0` |
| `float64` | `0` |
| `string` | `""` |
| `bool` | `false` |

`var имя тип` объявляет переменную без значения. В ней сразу лежит **нулевое значение**
(zero value) её типа, а не пустота или мусор.

```go
package main

import "fmt"

func main() {
	var n int
	var x float64
	var s string
	var ok bool

	fmt.Printf("%d %v %q %v\n", n, x, s, ok)
}
```

```
$ go run .
0 0 "" false
```

![Четыре переменные через var и их нулевые значения](images/03-var.png)

*1 — объявления через `var`, 2 — вывод. `%q` нужен, чтобы пустая строка была видна.*

Когда что:

- `:=` — значение известно сразу. Основной способ.
- `var x тип` — переменная начинает с нулевого значения, например счётчик с нуля.
- `var x тип = значение` — нужен другой тип, чем вывел бы компилятор:
  `var price float64 = 3`.

### Как принято в Go

- **Нулевое значение — готовое начало.** `var count int` вместо `count := 0`, если
  счёт начинается с нуля.
- **Имена в стиле MixedCaps:** `maxSize`, не `max_size` и не `MAX_SIZE`. Внутри функций
  — со строчной буквы: заглавная значит «видно снаружи» (шаг 2).
- **Длина имени — по области.** На три строки кода — `n`, `s`; на всю функцию — `total`.
- **Количество — в `int`:** половины штуки не бывает.
- **Неиспользуемая переменная — ошибка**, как неиспользуемый импорт (шаг 2).

### Типичные ошибки

| Сообщение | Причина |
|---|---|
| `declared and not used: x` | Переменная нигде не используется |
| `cannot use "три" (untyped string constant) as int value in assignment` | В `int` записывается текст в кавычках |
| `no new variables on left side of :=` | `:=` для уже объявленной переменной |
| `undefined: count` | Переменная не объявлена или опечатка в имени |
| `assignment mismatch: 1 variable but 2 values` | Дробь через запятую: `x := 3,5` |
| `%!d(string=три)` в выводе | Глагол не подходит к типу |
| `%!d(MISSING)` в выводе | Глаголов больше, чем значений |

Последние две программа печатает вместо значения; `go vet ./...` находит их без
запуска.

### Проверь себя

«Сломай» — в своём `main.go` в корне `pond`: измени строку, запусти `go run .`,
прочитай сообщение, верни как было (Cmd + Z) и проверь, что `go run .` снова работает.

1. Что напечатает?

   ```go
   x := 5
   x = 7
   fmt.Println(x)
   ```

   <details>
   <summary>Ответ</summary>

   `7`: присваивание заменило `5`.

   </details>

2. Что напечатает?

   ```go
   var s string
   fmt.Printf("[%s] %q\n", s, s)
   ```

   <details>
   <summary>Ответ</summary>

   `[] ""`. Нулевое значение строки — пустая строка; `%q` делает её видимой.

   </details>

3. Какой тип у `a := 10`, `b := 10.0`, `c := "10"`?

   <details>
   <summary>Ответ</summary>

   `int`, `float64`, `string`. Проверка: `fmt.Printf("%T %T %T\n", a, b, c)`.

   </details>

4. Сломай: первой строкой в `main` добавь `x := 1` и больше нигде `x` не используй.

   <details>
   <summary>Ответ</summary>

   ```
   # pond
   ./main.go:6:2: declared and not used: x
   ```

   В Go это ошибка, а не предупреждение.

   </details>

5. Сломай: первыми строками в `main` добавь `x := 1`, `x := 2` и `fmt.Println(x)`.

   <details>
   <summary>Ответ</summary>

   ```
   # pond
   ./main.go:7:4: no new variables on left side of :=
   ```

   `x` уже объявлена. Новое значение — через `=`.

   </details>

6. Сломай: замени `fmt.Println("Ква!")` на `fmt.Printf("%d\n", "Ква!")`, запусти,
   затем `go vet ./...`.

   <details>
   <summary>Ответ</summary>

   Программа напечатает `%!d(string=Ква!)` вместо кваканья: `%d` ждёт целое число.
   `go vet` находит это без запуска:

   ```
   main.go:6:14: fmt.Printf format %d has arg "Ква!" of wrong type string
   ```

   </details>
