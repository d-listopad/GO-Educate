# Шаг 3. Переменные и типы

## В прошлом уроке

В прошлом уроке мы разобрали устройство файла на Go: `package main`, `import "fmt"`,
функцию `main`, — запустили программу командой `go run .` и проверили её `gofmt`
и `go vet`. Проект стал модулем: `go.mod` создан и больше не трогается руками.
Код по-прежнему пишется в одном файле `main.go`. Работу ты сохраняла коммитом прямо
в `main`; с этого шага каждая задача делается в своей ветке и сдаётся через pull
request — об этом задача 1. Пока программа печатает только текст, записанный
в кавычках, — чтобы она работала с данными, которые меняются, нужны переменные.

## Чему мы научимся

- Хранить значения в переменных и заменять их по ходу программы.
- Выбирать тип значения: целое число, дробное число, текст, ответ «да или нет».
- Создавать переменные двумя способами, `:=` и `var`, и понимать, когда какой нужен.
- Знать, что лежит в переменной, которой ничего не присвоили.
- Печатать значения внутри фразы с помощью `fmt.Printf`.

Для чего это нужно знать: настоящие программы работают с данными, которые появляются
и меняются во время работы: количество, цена, температура, ответ человека. Чтобы
с ними что-то делать, программе нужно место, где их хранить.

## Где применяется. Как часто используется

Все слова из этого списка разобраны ниже, в «Объяснении материала».

- Переменные и `:=` — в каждой функции почти любой программы; `var` — реже.
- `int` и `string` — повседневно, `float64` — в измерениях и расчётах, `bool` —
  в проверках вида «если число больше трёх — …» (шаг 7).
- `fmt.Printf` — вывод в терминал.

## Объяснение материала

### Переменная

Программе часто нужно запомнить значение, чтобы обратиться к нему позже или заменить
его другим. Удобно представить коробочку с подписью: на подписи имя, внутри значение,
и его можно вынуть и положить новое.

**Переменная** (variable) — место в памяти компьютера, у которого есть имя и в котором
хранится одно значение. Память — то место, где программа держит свои данные, пока
работает; после завершения программы оно освобождается.

**Где набирать примеры.** Примеры урока набирай в `try/main.go`: каждый новый пример
заменяет предыдущий целиком, иначе в пакете окажутся две функции `main` и компилятор
ответит `main redeclared in this block`. Запускай `go run .` из папки `try`: в строке
приглашения путь `/workspaces/pond/try`. `main.go` в корне `pond` — твоя программа,
её меняют только задачи.

`try/main.go`
```go
package main

import "fmt"

func main() {
	count := 3
	fmt.Println(count)

	count = 5
	fmt.Println(count)
}
```

```
$ go run .
3
5
```

В этом файле две разные операции:

- `count := 3` — **объявление** (declaration): создать переменную `count` и сразу
  записать в неё значение `3`. Знак `:=` читается как «создать и записать».
- `count = 5` — **присваивание** (assignment): записать новое значение в переменную,
  которая уже существует. Старое значение `3` при этом теряется: переменная хранит
  одно значение, а не историю.

![Объявление и присваивание в программе](images/01-count.png)

*1 — объявление, 2 — присваивание, 3 — что напечатала программа: сначала `3`,
потом `5`.*

В `fmt.Println(count)` имя написано без кавычек: Go берёт значение, которое лежит
в переменной, и печатает `3`. `fmt.Println("count")` в кавычках напечатал бы само
слово `count`.

Важно понимать: знак `=` в Go — не равенство из математики, а действие: «вычислить
то, что справа, и записать в переменную слева». Поэтому порядок строк кода имеет
значение: первый `Println` печатает `3`, второй — `5`, хотя переменная одна.

Объявить переменную можно один раз, присваивать — сколько угодно. Так по строке видно,
что происходит: `:=` создаёт новую переменную, `=` меняет существующую, и опечатка
в имени не создаст незаметно вторую переменную.

### Тип

С числами можно считать, с текстом нельзя: `"3"` в кавычках — текст из одного символа,
а не число три. Поэтому каждая переменная создаётся под один вид значений.

**Тип** (type) — вид значений, которые может хранить переменная. Тип задаётся
при объявлении и больше не меняется. Раз тип известен заранее, компилятор ещё
до запуска проверяет, что с переменной делают допустимое. Четыре основных типа:

| Тип | Что хранит | Примеры значений |
|---|---|---|
| `int` | Целое число, в том числе отрицательное | `42`, `-7`, `0` |
| `float64` | Число с дробной частью | `3.14`, `-0.5`, `2.0` |
| `string` | Текст. В программировании его называют **строкой** | `"Привет"`, `""` — пустая строка, в ней ни одного символа |
| `bool` | Ответ «да или нет»: `true` (истина) или `false` (ложь) | `true`, `false` |

Не путай: строка (string) — значение-текст, строка кода — линия в файле, как в «номер
строки» из шага 2. Строковый литерал из шага 2 — значение типа `string`, записанное
прямо в коде. Где возможна путаница, урок пишет «строка кода».

Дробная часть отделяется точкой, а не запятой: `3.14`. Есть и другие числовые типы,
но в курсе достаточно `int` и `float64`.

При объявлении через `:=` тип не пишется. Компилятор определяет его сам по значению
справа: `3` — `int`, `3.0` — `float64`, `"3"` — `string`, `true` — `bool`.
Это называется **выводом типа** (type inference): тип выводится из значения.

Раз тип закреплён, записать в переменную значение другого типа нельзя. Замени в первой
программе урока строку `count = 5` на такую:

Фрагмент:
```go
count = "три" // ошибка: count хранит int, а "три" — строка
```

Текст после `//` до конца строки кода — **комментарий** (comment): пояснение для
человека, компилятор его пропускает. Набирать его не обязательно.

Текст ошибки — в «Типичных ошибках».

### Вывод значений: `fmt.Printf`

Часто значение нужно напечатать внутри фразы. Для этого есть `fmt.Printf`. Её удобно
представить как бланк с пропусками: текст бланка написан заранее, а в пропуски
по порядку вписываются значения.

`try/main.go`
```go
package main

import "fmt"

func main() {
	city := "Казань"
	temp := 12

	fmt.Printf("%s: %d градусов\n", city, temp)
}
```

```
$ go run .
Казань: 12 градусов
```

Первое значение в скобках — **строка формата** (format string): текст бланка
с пропусками на месте будущих значений. Пропуск — это **глагол** (verb): метка,
которая начинается со знака `%`. Так его называет документация Go: глагол говорит,
как напечатать значение. Значения после строки формата подставляются в глаголы
по порядку, через запятую: `city` — в `%s`, `temp` — в `%d`.

`\n` в конце — два символа, которые означают один: переход на новую строку.
`fmt.Println` переходит на новую строку сам, `fmt.Printf` — только если в строке
формата есть `\n`.

![Printf: строка формата и значения](images/02-printf.png)

*1 — глагол `%s` и значение `city`, которое в него подставится, 2 — глагол `%d`
и значение `temp`, 3 — `\n`, переход на новую строку, 4 — что напечатала программа.*

| Глагол | Что печатает | Пример | Результат |
|---|---|---|---|
| `%d` | Целое число | `Printf("%d", 42)` | `42` |
| `%s` | Строку как есть | `Printf("%s", "Go")` | `Go` |
| `%q` | Строку в кавычках: видна даже пустая строка | `Printf("%q", "Go")` | `"Go"` |
| `%v` | Любое значение в обычном виде | `Printf("%v", 3.5)` | `3.5` |

В таблице `fmt.` опущено для краткости. Ещё пригодится `%T` — тип значения:
`fmt.Printf("%T\n", 3)` напечатает `int`.

Глагол должен подходить к типу значения. Что будет, если перепутать, — в разделе
«Типичные ошибки».

### `var` и нулевое значение

Кроме `:=`, переменную можно объявить словом `var`. Тогда тип пишется явно,
а значение можно не указывать. Порядок: `var`, имя, тип, затем
`=` и значение, если нужно: `var price float64 = 3`.

Может показаться, что в переменной, которой ничего не присвоили, пусто или лежит что-то
случайное. В Go это не так: каждая переменная с момента объявления хранит значение.
Если его не указали, это **нулевое значение** (zero value) своего типа:

| Тип | Нулевое значение |
|---|---|
| `int` | `0` |
| `float64` | `0` |
| `string` | `""` |
| `bool` | `false` |

`try/main.go`
```go
package main

import "fmt"

func main() {
	var n int
	var x float64
	var s string
	var ok bool

	fmt.Printf("%d %v %q %v\n", n, x, s, ok)
}
```

```
$ go run .
0 0 "" false
```

![Четыре переменные через var и их нулевые значения](images/03-var.png)

*1 — четыре объявления через `var`: слово `var`, имя, тип, значения нет, 2 — что
напечатала программа: нулевые значения всех четырёх.*

`%q` нужен, чтобы увидеть пустую строку: `%s` не напечатал бы ничего.

Когда какой способ выбирать:

- `:=` — когда значение известно сразу. Это основной способ внутри функций.
- `var x тип` — когда переменная должна начать с нулевого значения, например счётчик,
  который начинается с нуля.
- `var x тип = значение` — когда нужен тип, отличный от того, что вывел бы компилятор:
  `var price float64 = 3` хранит дробное число, хотя из `3` компилятор вывел бы `int`.

В A Tour of Go встречаются `var` вне функций и запись `a, b := 1, 2`. В курсе они пока
не нужны: переменные объявляем внутри `main`, а `:=` вне функций не работает.

### Как принято в Go

**Нулевое значение полезно.** Переменная, объявленная через `var x int`, сразу готова
к работе, дописывать `= 0` не нужно: нулевое значение — осмысленное начальное
состояние, а не «ещё не заполнено». Выбор между `:=` и `var` — договорённость,
а не правило компилятора: по нему читатель видит намерение автора.

**Имена в стиле MixedCaps.** Имя из нескольких слов пишется слитно, каждое следующее
слово — с заглавной буквы: `maxSize`, `itemCount`. Подчёркивания не используются:
не `max_size` и не `MAX_SIZE`. Внутри функций имена начинаются со строчной: читатель
привык видеть в заглавной букве экспортируемое имя (шаг 2) и будет искать его снаружи.

**Длина имени — по области, где оно используется.** Переменная на три строки кода
называется коротко: `n`, `s`; переменная на всю функцию — полно: `total`, `price`.

**Количество — в целых числах.** То, что считают штуками, хранится в `int`: половины
штуки не бывает, и тип это гарантирует.

**Неиспользуемая переменная — ошибка**, как неиспользуемый импорт из шага 2: мусор
в коде компилятор не пропускает.

### Типичные ошибки

| Сообщение | Причина | Исправление |
|---|---|---|
| `declared and not used: x` | Переменная объявлена, но её значение нигде не используется. Вместо `x` — имя твоей переменной | Использовать переменную или удалить строку кода |
| `cannot use "три" (untyped string constant) as int value in assignment` | В переменную типа `int` записывается строка. `untyped string constant` — так компилятор называет строковый литерал | Записать значение того же типа, что у переменной |
| `no new variables on left side of :=` | `:=` применён к переменной, которая уже объявлена | Для нового значения использовать `=` |
| `undefined: count` | Присваивание через `=` переменной, которую не объявили, или опечатка в имени | Объявить через `:=` или исправить имя |
| `assignment mismatch: 1 variable but 2 values` | Дробная часть записана через запятую: `x := 3,5`. Компилятор видит два значения, `3` и `5` | Писать через точку: `3.5` |
| `%!d(string=три)` в выводе | Глагол не подходит к типу значения | Подобрать глагол по таблице или использовать `%v` |
| `%!d(MISSING)` в выводе | Глаголов в строке формата больше, чем переданных значений | Передать недостающее значение |

Последние две строки — не сообщения компилятора: программа запускается и печатает
их вместо значения. Команда `go vet ./...` из шага 2 находит такие вызовы `Printf`
заранее, без запуска. Её сообщение начинается с файла и строки кода без `./`:
`main.go:6:14: fmt.Printf format %d has arg "три" of wrong type string`. Если
передана переменная, вместо `"три"` будет её имя.

### Проверь себя

Сначала ответь сам, потом раскрой ответ. «Сломай» — в `try/main.go`: измени
программу из урока, запусти `go run .` из `try`, прочитай сообщение целиком,
затем верни пример в рабочее состояние.

1. Что напечатает этот фрагмент?

   ```go
   x := 5
   x = 7
   fmt.Println(x)
   ```

   <details>
   <summary>Ответ</summary>

   `7`. Строка `x = 7` записывает в переменную новое значение, старое `5` теряется.

   </details>

2. Что напечатает этот фрагмент?

   ```go
   var s string
   fmt.Printf("[%s] %q\n", s, s)
   ```

   <details>
   <summary>Ответ</summary>

   `[] ""`. Нулевое значение строки — пустая строка. `%s` печатает её как есть,
   то есть ничего, а `%q` — в кавычках, и пустоту становится видно.

   </details>

3. Какой тип выведет компилятор для `a := 10`, `b := 10.0`, `c := "10"`?

   <details>
   <summary>Ответ</summary>

   `int`, `float64`, `string`. Точка делает число дробным, кавычки делают значение
   строкой. Проверить можно глаголом `%T`: `fmt.Printf("%T %T %T\n", a, b, c)`.

   </details>

4. Сломай: объяви переменную и нигде её не используй. Что скажет компилятор?

   <details>
   <summary>Ответ</summary>

   `declared and not used: x`, где вместо `x` — имя твоей переменной. Неиспользуемая
   переменная в Go — ошибка, а не предупреждение.

   </details>

5. Сломай: объяви переменную через `:=`, а следующей строкой — ещё раз через `:=`
   с тем же именем.

   <details>
   <summary>Ответ</summary>

   `no new variables on left side of :=`. Объявить переменную можно один раз,
   новое значение записывается через `=`.

   </details>

6. Сломай: передай строку в глагол `%d`, запусти программу, затем выполни
   `go vet ./...`.

   <details>
   <summary>Ответ</summary>

   Программа запустится и напечатает `%!d(string=...)` вместо значения. `go vet`
   найдёт ошибку без запуска: `fmt.Printf format %d has arg ... of wrong type string`.

   </details>
