# Задача 1. Жабка представляется

## Контекст

Пока жабка квакает и здоровается. У неё есть имя, и она знает, сколько мух у неё в животе.
Эти сведения будут меняться, и программа должна их где-то хранить.

## Что нужно

После кваканья жабка называет своё имя и говорит, сколько мух у неё в животе. Имя
и число мух выбери сама.

<details>
<summary>Подсказка к задаче</summary>

Раздел урока «Вывод в терминал: *fmt.Printf*». Может, текст кваканья тоже стоит хранить
в одном месте?

</details>

## Где менять

*main.go* в корне *pond*, если хочешь — *README.md*. *go.mod* и *.devcontainer*
не трогаем.

## Git: первая ветка и pull request

С этой задачи работа идёт в отдельной ветке (branch) и сдаётся через pull request.
Что это и в каком порядке — раздел Git,
[3. Ветки и pull request](../../../Git/03-branches-and-pull-requests.md): прочитай его
до начала: ветка создаётся до правок. Имя ветки — *introduce-frog*.

## Критерии приёмки

- [ ] При запуске жабка называет имя и число мух в животе.
- [ ] Имя и число мух записаны каждое в одном месте.
      **Как проверить:** поменяй имя в одной строке и запусти — новое имя появится везде.
      То же с числом мух.
- [ ] Число мух — целое.
      **Как проверить:** временно добавь *fmt.Printf("%T\n", …)* со своей переменной —
      должно напечататься «int». Потом убери строку.
- [ ] Кваканье и приветствие работают как раньше.
- [ ] *gofmt -l .* и *go vet ./...* в корне *pond* ничего не выводят.
- [ ] Задача сдана через pull request, в описании — ответ на вопрос к разбору.
- [ ] После одобрения ветка влита в *main*, в Codespace снова *main* с последними
      изменениями.
      **Как проверить:** в корне *pond* набери по очереди — после *go run .* жабка
      представится:

      ```
      git switch main
      git pull
      go run .
      ```
