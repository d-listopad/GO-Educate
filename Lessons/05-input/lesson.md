# Шаг 5. Число из текста

## В прошлом уроке

В прошлом уроке мы разобрали операторы, преобразование типа и константы. Работа
по-прежнему идёт через ветки и pull request, код — в *main.go* в корне *pond*;
*.devcontainer* и *go.mod* не трогаем. Программа вычисляет новые значения, но все
числа записаны в коде: чтобы изменить число, надо править программу.

## Чему мы научимся

- Записывать в переменную результат функции.
- Подключать несколько пакетов одним *import*.
- Превращать текст в число функцией *strconv.Atoi*.
- Читать значение, заданное при запуске, функцией *os.Getenv*.

Данные приходят в программу снаружи текстом, а считать можно только с числами.

## Где применяется. Как часто используется

- Функции с результатом и *import* в скобках — почти в каждом файле.
- *strconv.Atoi* — везде, где число приходит текстом.
- *os.Getenv* — в программах, которые настраиваются при запуске.

### Функция с результатом и *strconv.Atoi*

Чтобы взять число снаружи, нужны две вещи: превратить текст в число и получить сам
текст при запуске. Начнём с первого. Функция может не печатать, а вычислить значение
и отдать его туда, где её вызвали: функция **возвращает значение** (return value).
Результат записывают в переменную.

*"42"* — строка, а не число, и сложить её с числом нельзя.
Функция *Atoi* из пакета *strconv* (string conversion, «преобразование строк»)
превращает текст в *int*. Имя читается «A to i»: из текста (A) в целое число
(i, integer). Пакет из стандартной
библиотеки, как *fmt*. Несколько пакетов подключают одним *import* в круглых
скобках, по пакету на строку.

Текст может не быть числом, поэтому *Atoi* возвращает два значения: число и **ошибку**
(error). Это не ошибка компилятора, а значение: программа работает, а ошибка сообщает,
что не вышло. Два результата записываются в две переменные через запятую.

![strconv.Atoi в программе](images/01-strconv.png)

*На кадре — пример урока, не твой файл.*

Если всё в порядке, ошибка равна *nil* («ничего», печатается «&lt;nil&gt;»). Если текст
не число (*"сорок"*, лишний пробел, пустая строка), *Atoi* возвращает *0* и ошибку:
«parsing "сорок": invalid syntax» — «в тексте "сорок" не число».

Во втором вызове *err* уже объявлена, и это допустимо: ':=' требует хотя бы одну
новую переменную слева — *m*, а в *err* записывается новое значение.

### Отбросить значение: «_»

В программе ошибка пока не нужна: проверять её научимся позже. Но оставить *err*
неиспользованной нельзя: неиспользуемая переменная — ошибка.
Вместо имени переменной ставится «_» — **пустой идентификатор** (blank identifier),
то есть «пустое имя»: значение никуда не записывается.

Фрагмент, *s* — строка с числом:
```go
n, _ := strconv.Atoi(s)
```

Если текст не число, программа молча продолжит с нулём.

### Значение при запуске: *os.Getenv*

Текст в число превращать умеем. Осталось получить этот текст при запуске, не меняя
код. **Переменная окружения** (environment variable) — имя и текстовое значение, которые
задаются в терминале перед командой запуска. Это не переменная Go и не среда Codespace:
в коде её не объявляют. Программа читает её функцией *Getenv* (get environment)
из пакета *os* (operating system). Если переменная не задана, *os.Getenv* возвращает
пустую строку.

Запуск с переменной окружения — она пишется в терминале перед командой:

```sh
COUNT=21 go run .
```

![Переменная окружения при запуске](images/02-env.png)

*На кадре — пример урока, не твой файл.*

Без неё, командой *go run .*, программа напечатает «текст "", число 0».

*COUNT=21* действует только на этот запуск. Пробелов вокруг '=' нет: терминал делит
строку по пробелам и *COUNT = 21* примет за команду *COUNT* — ответит
«bash: COUNT: command not found» (bash — программа, которая читает команды в терминале).
Имена переменных окружения принято писать заглавными латинскими: это соглашение
терминала, а не Go.

### Как принято в Go

- **Преобразования только явные:** строка сама числом не становится, нужен *strconv.Atoi*.
- **Ошибку не отбрасывают молча:** «_» вместо ошибки — временно, пока мы не умеем
  её проверять.

### Типичные ошибки

| Сообщение | Причина | Исправление |
|---|---|---|
| «assignment mismatch: 1 variable but strconv.Atoi returns 2 values» | Принято одно значение из двух | *n, err :=* или «n, _ :=» |
| «no new variables on left side of :=» | Слева от ':=' нет новой переменной | Для объявленных — '=' |
| «undefined: strconv» | Пакет не подключён в *import* | Добавить *"strconv"* |
| «bash: COUNT: command not found» | Пробелы вокруг '=' | *COUNT=21 go run .* |

### Проверь себя

В вопросах «Что напечатает» предскажи вывод, в «Сломай» — сообщение компилятора.
«Сломай» делается в своём *main.go* в корне *pond*: измени, запусти *go run .*,
прочитай сообщение и верни как было (Cmd + Z).

1. Что напечатает этот фрагмент?

   ```go
   n, err := strconv.Atoi("7")
   fmt.Println(n*2, err)
   ```

   <details>
   <summary>Ответ</summary>

   «14 &lt;nil&gt;»: текст стал числом *7*, ошибки нет.

   </details>

2. Сломай: в конец *main* добавь *n := strconv.Atoi("5")* и *fmt.Println(n)*, а строку
   *import "fmt"* замени на *import* в скобках с *"fmt"* и *"strconv"*, как в примере
   урока.

   <details>
   <summary>Ответ</summary>

   «assignment mismatch: 1 variable but strconv.Atoi returns 2 values»: принять нужно
   оба значения, второе можно отбросить через «_».

   </details>

3. Что напечатает этот фрагмент?

   ```go
   n, _ := strconv.Atoi(" 7")
   fmt.Println(n)
   ```

   <details>
   <summary>Ответ</summary>

   *0*: пробел перед *7* — текст уже не число, *Atoi* вернула *0* и ошибку,
   а ошибка отброшена.

   </details>

4. Что напечатает программа из «Значение при запуске» по команде *COUNT=пять go run .*?

   <details>
   <summary>Ответ</summary>

   «текст "пять", число 0»: *Atoi* вернула *0* и ошибку, а ошибка отброшена —
   программа о проблеме не сообщила.

   </details>
