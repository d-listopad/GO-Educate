# Шаг 5. Число из текста

## В прошлом уроке

В прошлом уроке мы разобрали операторы, преобразование типа и константы. Работа
по-прежнему идёт через ветки и pull request, код — в `main.go` в корне `pond`;
`.devcontainer` и `go.mod` не трогаем. Но все числа записаны в коде:
чтобы изменить число, надо править программу.

## Чему мы научимся

- Записывать в переменную результат, который возвращает функция.
- Подключать несколько пакетов одним `import`.
- Превращать текст в число функцией `strconv.Atoi`.
- Читать значение, заданное при запуске, функцией `os.Getenv`.

Данные приходят в программу снаружи текстом, а считать можно только с числами.

## Где применяется. Как часто используется

Функции с результатом и `import` в скобках — почти в каждом файле. `strconv.Atoi` —
везде, где число приходит текстом; `os.Getenv` — в программах, которые настраиваются
при запуске.

## Объяснение материала

Под каждым примером — что он печатает.

### Функция с результатом и `strconv.Atoi`

Функция может не печатать, а вычислить значение и отдать его туда, где её вызвали:
функция **возвращает значение** (return value). Результат записывают в переменную.

`"42"` — строка, а не число, и сложить её с числом нельзя (шаг 4, «Типичные ошибки»).
Функция `Atoi` из пакета `strconv` (string conversion, «преобразование строк»)
превращает текст в `int`: «A to i» — из текста в integer. Пакет из стандартной
библиотеки (шаг 2), как `fmt`. Несколько пакетов подключают одним `import` в круглых
скобках, по пакету на строку.

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	n, err := strconv.Atoi("42")
	fmt.Println(n+1, err)

	m, err := strconv.Atoi("сорок")
	fmt.Println(m, err)
}
```

```
$ go run .
43 <nil>
0 strconv.Atoi: parsing "сорок": invalid syntax
```

![strconv.Atoi в программе](images/01-strconv.png)

*1 — два пакета в одном `import`, 2 — две переменные для двух результатов,
3 — вызов `strconv.Atoi`, 4 — вывод.*

Текст может не быть числом, поэтому `Atoi` возвращает два значения: число и **ошибку**
(error). Это не ошибка компилятора, а значение: программа работает, а `err` сообщает,
что не вышло. Если всё в порядке, ошибка равна `nil` («ничего», печатается `<nil>`).
Если текст не число (`"сорок"`, пробел, пустая строка), `Atoi` возвращает `0`
и ошибку: `parsing "сорок": invalid syntax` — «в тексте "сорок" не число».

Два результата записываются в две переменные через запятую. Во второй строке `err`
уже есть, и это допустимо: `:=` требует хотя бы одну новую переменную слева — `m`.

### Отбросить значение: `_`

Проверять ошибку научимся позже, а пока её можно отбросить: вместо имени ставится `_` —
**пустой идентификатор** (blank identifier), значение выбрасывается.

Фрагмент, `s` — строка с числом:
```go
n, _ := strconv.Atoi(s)
```

Если текст не число, программа молча продолжит с нулём — поэтому в рабочем коде
ошибку не отбрасывают.

### Значение при запуске: `os.Getenv`

**Переменная окружения** (environment variable) — имя и текстовое значение, которые
задаются в терминале перед командой запуска. Это не переменная Go: в коде её
не объявляют. Программа читает её функцией `Getenv` (get environment) из пакета `os`
(operating system, стандартная библиотека). Если переменная не задана, `os.Getenv`
возвращает пустую строку.

```go
package main

import (
	"fmt"
	"os"
	"strconv"
)

func main() {
	s := os.Getenv("COUNT")
	n, _ := strconv.Atoi(s)
	fmt.Printf("текст %q, число %d\n", s, n*2)
}
```

Запуск с переменной окружения и без:

```
$ COUNT=21 go run .
текст "21", число 42
$ go run .
текст "", число 0
```

![Переменная окружения при запуске](images/02-env.png)

*1 — чтение переменной окружения в коде, 2 — значение перед командой в терминале,
3 — вывод.*

`COUNT=21` действует только на этот запуск. Пробелов вокруг `=` нет: терминал делит
строку по пробелам и `COUNT = 21` примет за команду `COUNT` — ответит
`bash: COUNT: command not found` (bash — программа, которая читает команды в терминале).
Имена переменных окружения принято писать заглавными латинскими: это соглашение
терминала, а не Go.

### Как принято в Go

- **Преобразования только явные:** строка становится числом только через `strconv.Atoi`.
- **Ошибку не выбрасывают молча.** В курсе `_` вместо ошибки допустим, пока мы не умеем
  её проверять; потом эту строку в `pond` ты исправишь.

### Типичные ошибки

| Сообщение | Причина | Исправление |
|---|---|---|
| `assignment mismatch: 1 variable but strconv.Atoi returns 2 values` | Принято одно значение из двух | `n, err :=` или `n, _ :=` |
| `no new variables on left side of :=` | Слева от `:=` нет новой переменной | Для объявленных — `=` |
| `undefined: strconv` | Пакет не подключён в `import` | Добавить `"strconv"` |
| `bash: COUNT: command not found` | Пробелы вокруг `=` | `COUNT=21 go run .` |

### Проверь себя

Сначала ответь сама, потом раскрой ответ. «Сломай» — в своём `main.go` в корне `pond`:
измени, запусти `go run .`, прочитай сообщение и верни как было (Cmd + Z).

1. Что напечатает этот фрагмент?

   ```go
   n, err := strconv.Atoi("7")
   fmt.Println(n*2, err)
   ```

   <details>
   <summary>Ответ</summary>

   `14 <nil>`: текст стал числом `7`, ошибки нет.

   </details>

2. Сломай: подключи `"strconv"` в `import` (в скобках, как в уроке), а в конец `main`
   добавь `n := strconv.Atoi("5")` и `fmt.Println(n)`.

   <details>
   <summary>Ответ</summary>

   `assignment mismatch: 1 variable but strconv.Atoi returns 2 values`: принять нужно
   оба значения, второе можно отбросить через `_`.

   </details>

3. Что напечатает этот фрагмент?

   ```go
   n, _ := strconv.Atoi(" 7")
   fmt.Println(n)
   ```

   <details>
   <summary>Ответ</summary>

   `0`: пробел перед `7` — текст уже не число, `Atoi` вернула `0` и ошибку,

   </details>

   </details>
