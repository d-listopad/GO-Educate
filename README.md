# GO Educate

Уроки по Go.

## Структура

- `Introduction/` — что сделать до начала изучения языка: окружение, инструменты, как работать с этим репозиторием.
- `Git/` — как сохранять работу и сдавать задачи: коммиты, GitHub, ветки и pull request.
- `Lessons/` — уроки по темам. Каждая тема в своей папке: файл урока и папка с задачами.

Задачи выполняются в отдельном репозитории `pond`: весь курс — одна программа «Пруд»,
которая растёт от задачи к задаче. Как его завести — в `Introduction/`.
